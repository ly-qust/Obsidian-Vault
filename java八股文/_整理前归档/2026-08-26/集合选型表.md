| 结构                | 底层结构                | 查询              | 插入/删除                   | 是否有序 | 线程安全 | 常见场景               |
| ----------------- | ------------------- | --------------- | ----------------------- | ---- | ---- | ------------------ |
| ArrayList         | 动态数组                | 下标 O(1)，查找 O(n) | 尾部平均 O(1)，中间 O(n)       | 是    | 否    | 查询多、需要下标访问         |
| LinkedList        | 双向链表                | O(n)            | 已定位节点时 O(1)，定位过程可能 O(n) | 是    | 否    | 头尾操作、队列或双端队列       |
| HashMap           | 哈希表：数组＋链表/红黑树       | 平均 O(1)         | 平均 O(1)                 | 不保证  | 否    | 普通 Key-Value 映射    |
| HashSet           | 基于 HashMap，元素作为 key | 平均 O(1)         | 平均 O(1)                 | 不保证  | 否    | 去重、判断元素是否存在        |
| ConcurrentHashMap | 并发哈希表               | 平均 O(1)         | 平均 O(1)                 | 不保证  | 是    | 多线程共享 Key-Value 数据 |
