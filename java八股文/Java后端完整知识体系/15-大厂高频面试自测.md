# 大厂高频面试自测

## 使用方法

每题先闭卷回答 30 秒，再扩展到 90 秒。合格答案至少包含：结论、机制、场景、边界。项目题还必须给证据。

评分：

- 0：不会或结论错误。
- 1：只会定义。
- 2：能讲机制。
- 3：能讲机制、边界和项目场景。
- 4：能继续完成排障、容量或系统设计追问。
