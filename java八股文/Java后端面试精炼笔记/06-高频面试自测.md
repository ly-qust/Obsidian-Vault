# 高频面试自测

[[05-MyBatis核心|上一篇：MyBatis]] · [[00-Java后端面试知识地图|返回知识地图]]

> [!tip] 用法
> 每题先口述 30～60 秒。回答必须包含：结论、机制、场景、边界。

1. JVM 运行时数据区哪些线程私有，哪些线程共享？方法区与元空间是什么关系？
2. 堆 OOM 和 StackOverflowError 常见原因分别是什么？怎样拿证据排查？
3. Java 对象从 `new` 到可使用经历哪些阶段？“对象复制给栈引用”哪里不准确？
4. 常见 GC Roots 有哪些？可达是否等于永久不回收，不可达是否立即回收？
5. 标记-清除、复制、标记-整理的空间与移动成本如何取舍？
6. Spring Boot 自动配置为什么能自动，又为什么会对用户自定义 Bean 退让？
7. Spring AOP 代理与 `@Transactional` 的调用链是什么？
8. 同类自调用为什么可能使事务失效？哪些解决方式更清晰？
9. 异常被 catch、checked exception、RuntimeException 分别怎样影响常见默认回滚？
10. REQUIRED 和 REQUIRES_NEW 如何选择？REQUIRES_NEW 有什么资源与一致性边界？
11. Redis 预占与 MySQL 条件扣减为什么同时存在？
12. Redis 预占成功但数据库扣减或发券失败，补偿怎样保证最终可靠？
