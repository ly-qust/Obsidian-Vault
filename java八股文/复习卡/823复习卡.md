## 2. Java 集合选型表

|集合|底层结构|查询|插入/删除|有序|线程安全|场景|
|---|---|---|---|---|---|---|
|ArrayList|动态数组|下标 O(1)，查找 O(n)|尾部平均 O(1)，中间 O(n)|是|否|查询多、下标访问|
|LinkedList|双向链表|O(n)|已定位节点 O(1)，定位可能 O(n)|是|否|头尾操作、双端队列|

## 3. 三张超短复习卡

### HashMap

```
结构：数组 + 链表/红黑树
get：key → hash → 桶 → equals → value
put：定位桶 → 相同 key 更新，否则新增
扩容：负载升高 → 扩大 table → 调整桶分布
边界：平均 O(1)；并发写不安全
```

### ConcurrentHashMap

```
目的：线程安全 + 较好的并发能力
JDK 8：CAS + 局部 synchronized
边界：单个方法安全 ≠ 复合操作原子
改法：putIfAbsent / computeIfAbsent
```

### 异常 / 泛型 / Stream

```
异常：
Throwable → Error / Exception
Checked：捕获或声明
RuntimeException：编译器通常不强制处理
后端：全局异常处理器统一响应

泛型：
编译期类型检查
减少强制转换
运行时部分类型信息擦除

Stream：
filter/map：惰性中间操作
toList/count/forEach：终止操作
复杂、副作用多时考虑普通循环
```

## 4. 数据结构复杂度表

|结构|访问|查找|插入|删除|
|---|---|---|---|---|
|数组|O(1)|O(n)|中间 O(n)|中间 O(n)|
|链表|O(n)|O(n)|已定位 O(1)|已定位 O(1)|
|哈希|—|平均 O(1)|平均 O(1)|平均 O(1)|

- 数组 O(1)：连续存储，可以通过首地址和下标计算位置。
- 链表 O(1) 插删：前提是已经定位到节点；寻找节点仍可能 O(n)。
- 哈希 O(1)：只指平均情况，冲突严重时可能退化。
