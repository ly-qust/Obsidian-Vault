# ⭐ 第一章：知识导入（15 min）

## 1.1 什么是图（Graph）？

图由 **顶点（Vertex）** 和 **边（Edge）** 组成。

根据是否有方向，分为：

|类型|名称|举例|
|---|---|---|
|有向图|Directed Graph|食物链、课程先修|
|无向图|Undirected Graph|社交网络、道路图|

根据是否有环，分为：

|类型|名称|含义|
|---|---|---|
|有环图|cyclic|存在回到自己的路径|
|无环图|acyclic|不能回到自己|

---

## 1.2 什么是有向无环图（DAG）？

**DAG：Directed Acyclic Graph（有向无环图）**

特点：

- 所有边有方向
    
- 不存在环
    
- 至少存在一个 **入度为 0** 的点（源点）
    
- 至少存在一个 **出度为 0** 的点（汇点）
    

DAG 是很多现实问题的数学模型：

|应用|场景|
|---|---|
|课程依赖|学 A → 学 B|
|软件依赖|npm / pip 的安装顺序|
|项目构建|Makefile 依赖图|
|食物网|捕食关系|
|拓扑排序|按顺序处理任务|

# ⭐ 第二章：拓扑排序（Topological Sort）（40 min）

拓扑排序是 **对 DAG 的所有点进行线性排序，使得所有有向边 u → v 中，u 都排在 v 前面**。

## 2.1 拓扑排序的适用情况（记忆口诀）

> **只要出现“有依赖关系”“先做啥再做啥” 都适用拓扑排序**

典型场景：

1. **任务调度**：先做 A，再做 B
    
2. **课程表安排**：课程先修图
    
3. **食物链中物种顺序**
    
4. **编译依赖**：先编译基础模块
    
5. **DAG 动态规划的基础结构**
    

如果图中有环 → 无法拓扑排序。

---

## 2.2 拓扑排序特点（总结）

- 只适用于 **DAG**
    
- 至少存在一种拓扑序；不一定唯一（多源点时不同选择会产生不同序列）
    
- 输出顺序不是唯一，但必须满足“前驱先出现”
    

---

## 2.3 拓扑排序模板：Kahn 入度法（重点）

> 入度 = 指向该点的边的数量

### 代码模板（考试版 / 比赛版）：

```cpp
vector<int> e[N];
int d[N];    // 入度
queue<int> q;

void topsort() {
    for(int i = 1; i <= n; i++){
        if(d[i] == 0)
            q.push(i);
    }

    while(!q.empty()){
        int u = q.front(); q.pop();
        topo.push_back(u); // 存结果

        for(int v : e[u]){
            d[v]--;
            if(d[v] == 0)
                q.push(v);
        }
    }
}
```

---

## 2.4 拓扑排序的时间复杂度

```
O(n + m)
```

即：遍历所有点 + 所有边。

非常快，适合大图。

---

## 2.5 拓扑排序易错点

❌ 入度减少后忘记判断是否为 0  
❌ 入度初始读法错  
❌ 未判断图是否有环（拓扑序长度 < n）  
❌ 未对所有入度为 0 的点初始化入队

# ⭐ 第三章：DAG 上的动态规划（40 min）

拓扑排序的最大意义：

> **保证 DP 不会反复回到前面，从而可以从前往后推导。**

如果不是 DAG，最长路会变成 NP-hard（很难）。

---

# 📌 3.1 DAG DP 经典模型 1：最长路径

适用情况：

- 图无环
    
- 每条边有权值
    
- 求从某点出发的最远路径
    

DP 方程：

```
len[v] = max(len[v], len[u] + w);
```

## 初始化

```
len[s] = 0
len[其他点] = -inf
```

## 代码模板（与你 PPT 相同）

```cpp
len[v] = max(len[v], len[p] + w);
```

---

# 📌 3.2 DAG DP 经典模型 2：路径计数（本节重点）

适用情况：

- 边没有权值
    
- 要求所有路径数量
    
- DAG 上统计从源点到汇点的路径条数
    

DP 方程：

```
dp[v] += dp[u];
```

初始化：

```
入度为 0 的点 dp = 1
```

最终答案：

```
所有出度为 0 的点 dp 之和
```

## 4.3 题目 3：最大食物链计数 123OJ 11322（重点）

问题：统计所有从生产者到消费者的完整食物链数量。

生物网是 DAG。

- 入度 0 → 生产者（链的起点）
    
- 出度 0 → 消费者（链的终点）
    

### 核心 DP

```
dp[producer] = 1
dp[v] += dp[u]  (u → v)
```

答案：

```
所有消费者 dp 之和
```

### 模板代码（标准解法）

```cpp
// dp[u] = number of ways to reach u
for(int i=1; i<=n; i++){
    if(d[i] == 0){
        dp[i] = 1;
        q.push(i);
    }
}

while(!q.empty()){
    int u = q.front(); q.pop();
    for(int v : e[u]){
        dp[v] = (dp[v] + dp[u]) % MOD;
        d[v]--;
        if(d[v] == 0) q.push(v);
    }
}

// consumers = 出度为 0
for(int i=1; i<=n; i++)
    if(out[i] == 0)
        ans = (ans + dp[i]) % MOD;
```
