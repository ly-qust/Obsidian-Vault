

这道题的要求很简单：给一个字符串，问最少插入几个字符能让它变成回文串。

### 思路一：区间 DP（直观构造法）

当我们处理回文问题时，最自然的思路是从**两端**向中间看。

- **状态定义**：f[i][j] 表示把子串 s[i...j] 变成回文串所需的最少插入次数。
    
- **核心逻辑**：
    
    1. 如果 s[i] == s[j]：头尾已经匹配了，不需要操作。那么 f[i][j] = f[i+1][j-1]。
        
    2. 如果 s[i] != s[j]：我们有两个选择：
        
        - 在右边补一个 s[i]，剩下的问题变成 f[i+1][j]。
            
        - 在左边补一个 s[j]，剩下的问题变成 f[i][j-1]。
            
        - 取最小值再加 1 次操作：f[i][j] = min(f[i+1][j], f[i][j-1]) + 1。
            

**注意：区间 DP 的遍历顺序很重要，一定要**先枚举区间长度**，确保算大区间时，内部的小区间已经算好了。

### 思路二：LCS（等价转换法）

这是一个非常巧妙的转化：**最少插入次数 = 原串长度 - 最长回文子序列（LPS）长度**。  
而求一个串的 LPS，等价于求**原串**与**反转后的串**之间的**最长公共子序列（LCS）**。

- **结论**：ans = n - LCS(s, reverse(s))。
    
- **优点**：代码极其标准化，不容易写错。
