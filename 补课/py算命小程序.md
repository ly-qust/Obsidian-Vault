## 四、程序整体逻辑讲解（10~30分钟）

### 算命程序的核心流程图：

```text
开始
  ↓
输入个人信息
  ↓
是否查过？
  ├─ 是 → 显示之前的命运
  └─ 否 → 随机生成新命运
  ↓
是否继续？
  ├─ 是 → 重新开始
  └─ 否 → 结束程序
```

### 涉及的知识点：

|功能|技术|
|---|---|
|随机命运|random.randint()|
|存储结果|字典 dict|
|无限循环|while True|
|图形输入|easygui.multenterbox|
|弹窗按钮|easygui.ynbox|

讲解比喻：

- 字典 = 记事本
    
- key = 输入的信息
    
- value = 命运结果

## 五、代码逐块讲解（30~50分钟）

### 1. 导入模块

```python
import random
import easygui
```

解释：

- random：负责“随机命运”
    
- easygui：负责弹出输入框和消息框
    

---

### 2. 命运列表

```python
result = [
    "你在巴黎街头乞讨",
    "你在迪拜塔厕所里挖金子",
    "你是亿万富翁",
    "你是仙女"
]
```

说明：

- 这是一个列表
    
- 每一项是一个命运
    
- 后面用随机索引获取
    

---

### 3. 创建命运数据库

```python
myk = {}
```

解释：

- 空字典
    
- 用来存：输入信息 → 命运
    

结构示例：

```python
{
"['张三','男','2002-1-1']": "你是亿万富翁"
}
```

---

### 4. 无限循环

```python
while True:
```

解释：

- 程序一直运行
    
- 直到手动 break 退出
    

---

### 5. 输入信息窗口

```python
x = easygui.multenterbox(
    '请输入你的信息',
    '算命网',
    ['姓名', '性别', '生日']
)
```

作用：

- 弹出多个输入框
    
- 返回一个列表
    

再转为字符串：

```python
x = str(x)
```

用于作为字典键。

---

### 6. 判断是否查过

```python
if x in myk:
```

解释：

- 判断是否已有记录
    
- 有 → 读取旧命运
    
- 没 → 重新生成
    

已存在情况：

```python
a = easygui.ynbox(myk[x], '算命网', ['我不信命', '我很满意'])
```

不存在情况：

```python
index = random.randint(0, 3)
a = easygui.ynbox(result[index], '算命网', ['我不信命', '我很满意'])
myk[x] = result[index]
```

---

### 7. 是否退出

```python
if a == False:
    break
```

按钮说明：

- False = 点击“不信命”
    
- True = 点击“满意”

## 六、完整示范代码（教师演示）

```python
import random
import easygui

result = [
    "你在巴黎街头乞讨",
    "你在迪拜塔厕所里挖金子",
    "你是亿万富翁",
    "你是仙女"
]

myk = {}

while True:
    x = easygui.multenterbox(
        '请输入你的信息',
        '算命网',
        ['姓名', '性别', '生日']
    )

    x = str(x)

    if x in myk:
        a = easygui.ynbox(myk[x], '算命网', ['我不信命', '我很满意'])
    else:
        index = random.randint(0, 3)
        a = easygui.ynbox(result[index], '算命网', ['我不信命', '我很满意'])
        myk[x] = result[index]

    print(myk)

    if a == False:
        break
```
