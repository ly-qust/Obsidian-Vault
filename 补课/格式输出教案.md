# 📘 三、授课笔记

## 1. 什么是输入和输出？

我们写程序时，需要让电脑：

- **读入**我们给的数据 → 输入（`scanf`）
    
- **显示**结果给我们 → 输出（`printf`）
    

就像问答题：  
👉 你问电脑：这里有个数字是多少？  
👉 电脑回答：我算出来是 xxx！

✨ 程序就靠这两个函数和我们交流。

---

## 2. 头文件（必须写）

```c
#include <cstdio>
```

这是告诉电脑：“我要用 scanf 和 printf 啦！”

---

## 3. scanf 格式（输入）

语法：

```c
scanf("类型控制符", &变量名);
```

例子：

```c
int a;
scanf("%d", &a);
```

📌 小学生易错点：

- 一定要写 **&**（取地址符号）
    
- 字符类型 `%c` 输入不会自动跳过空格，要注意！
    

---

## 4. printf 格式（输出）

语法：

```c
printf("类型控制符", 变量名);
```

例子：

```c
printf("%d", a);
```

---

## 5. 常见类型与控制符

| 类型        | 说明     | 控制符  |
| --------- | ------ | ---- |
| int       | 整数     | %d   |
| long long | 更大的整数  | %lld |
| float     | 小数     | %f   |
| double    | 更精确的小数 | %lf  |
| char      | 单个字符   | %c   |

---

## 6. 控制小数位数（重点）

默认输出 **6 位小数**，例如：

```c
printf("%f", x);   // 会输出 6 位小数
```

想要控制：

```c
printf("%.3f", x); // 保留3位小数
printf("%.6lf", y); // double 保留6位
```

示例：

```c
float a;
double b;
scanf("%f %lf", &a, &b);

printf("%.3f\n", a);
printf("%.6lf\n", b);
```

---

## 7. 整数按固定宽度输出（很重要）

### （1）补空格（默认右对齐）

```c
printf("%8d", a);
```

含义：

- 8 字符宽度
    
- 不够 → 左边补空格
    
- 太长 → 正常输出
    

示例输出：

```
      12
```

---

### （2）补零

```c
printf("%08d", a);
```

示例：

```
00000012
```

---

### （3）左对齐

```c
printf("%-8d", a);
```

示例：

```
12      
```

---

## 8. 实例代码（课堂演示）

### 示例1：各种格式输出

```c
#include <cstdio>
int main() {
    double a;
    scanf("%lf", &a);
    printf("%f\n", a);
    printf("%.5f\n", a);
    printf("%e\n", a);   // 科学计数法
    printf("%g\n", a);   // 自动调整格式
    return 0;
}
```

---

### 示例2：A × B（注意 long long）

```c
#include <iostream>
using namespace std;
int main(){
    long long a, b, c;
    cin >> a >> b;
    c = a * b;
    cout << c;
    return 0;
}
```

---

### 示例3：输出固定宽度

```c
#include <cstdio>
int main(){
    int a, b, c;
    scanf("%d%d%d", &a, &b, &c);
    printf("%8d %8d %8d", a, b, c);
    return 0;
}
```

# 📝 四、板书内容（教师黑板书写）

```
scanf / printf

常见类型：
int → %d
long long → %lld
float → %f
double → %lf
char → %c

控制小数：
%.nf   （n = 小数位数）

控制宽度：
%8d     → 补空格
%08d    → 补零
%-8d    → 左对齐
```
