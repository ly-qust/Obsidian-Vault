# **Linux 常用命令 · 详细总结表（完整版）**

---

## **1. 文件与目录操作**

|命令|作用|常用参数 / 说明|示例|
|---|---|---|---|
|`pwd`|显示当前所在目录|——|`pwd`|
|`ls`|列出目录内容|`-l`详细；`-a`包含隐藏；`-h`带单位大小；`-t`按时间排序|`ls -alh`|
|`cd`|切换目录|`cd ~` 回 home；`cd -` 上次目录|`cd /var/log`|
|`mkdir`|创建目录|`-p` 递归创建|`mkdir -p a/b/c`|
|`rm`|删除文件或目录|`-r` 删除目录；`-f` 强制 **危险**|`rm -rf test/`|
|`cp`|复制文件/目录|`-r` 复制目录；`-p` 保留权限|`cp -r conf/ backup/`|
|`mv`|移动/重命名|既可重命名也能移动|`mv a.txt b.txt`|
|`touch`|创建空文件 / 更新时间戳|——|`touch index.html`|

---

## **2. 文件内容查看**

|命令|用途|特点|示例|
|---|---|---|---|
|`cat`|查看小文件|一次性全部显示|`cat /etc/hosts`|
|`tac`|反向输出|从最后一行开始显示|`tac logfile`|
|`more`|分页查看|旧工具，可翻页|`more large.txt`|
|`less`|分页查看（最常用）|支持搜索 `/text`、滚动|`less /var/log/messages`|
|`head`|查看文件前 n 行|默认前 10 行|`head -20 file`|
|`tail`|看文件末尾 n 行|`-f` 实时追踪日志|`tail -f app.log`|
|`nl`|显示带行号内容|类似 cat，但加行号|`nl file.txt`|

---

## **3. 搜索查找（非常重要）**

### **文件查找（find）**

|命令|用途|示例|
|---|---|---|
|`find /path -name "*.log"`|按文件名查找|搜索日志文件|
|`find / -type f -size +100M`|查找超过 100MB 文件|清理空间常用|
|`find /var -mtime -1`|查找最近一天改动的文件|查问题时用|

### **内容查找（grep）**

|命令|用处|示例|
|---|---|---|
|`grep "ERROR" file.log`|查包含字符串的行||
|`grep -n "text" file`|显示行号||
|`grep -i "abc"`|忽略大小写||
|`grep -r "hello" /var/www`|递归搜索目录||
|`grep -A 3 -B 3 "fail"`|显示匹配前后 3 行||

组合常见：

```bash
ps -ef | grep nginx
netstat -tulpn | grep 8080
```

## **4. 权限管理**

|命令|作用|说明|示例|
|---|---|---|---|
|`ls -l`|查看权限|`rwx` 格式|`ls -l`|
|`chmod`|修改权限|数字法：755 / 644 / 777（危险）|`chmod 755 file.sh`|
|`chown`|修改所有者和组|`user:group`|`chown root:root a.txt`|
|`chgrp`|改用户组|——|`chgrp admin file`|

数字含义：

- 4 = r
    
- 2 = w
    
- 1 = x  
    例如：7 = rwx，6 = rw

## **5. 用户与组**

|命令|作用|示例|
|---|---|---|
|`useradd name`|创建用户|`useradd tom`|
|`passwd name`|设置密码|`passwd tom`|
|`userdel -r name`|删除用户并删除 home||
|`groupadd dev`|创建组||
|`usermod -aG wheel user`|添加用户到组|sudo 管理常用|
|`id user`|查看 UID/GID||

切换用户：

- `su - root`
    
- `sudo <cmd>`（推荐方式）

## **6. 压缩与解压**

### **tar（最常用）**

|操作|命令|
|---|---|
|打包|`tar -cvf a.tar dir/`|
|压缩（gzip）|`tar -zcvf a.tar.gz dir/`|
|解压|`tar -xvf a.tar.gz`|
|解压到指定目录|`tar -zxvf a.tar.gz -C /tmp/`|

### **zip/unzip**

|操作|命令|
|---|---|
|压缩|`zip a.zip file1 file2`|
|解压|`unzip a.zip`|

## **7. 进程管理（排错必会）**

|命令|用途|示例|
|---|---|---|
|`ps -ef`|查看所有进程|`ps -ef|
|`top`|实时 CPU 内存占用||
|`htop`|更好用（需安装）||
|`pidof name`|获取进程 PID|`pidof nginx`|
|`kill PID`|终止进程||
|`kill -9 PID`|强制杀死||
|`pgrep name`|查进程 ID|`pgrep nginx`|

后台运行：

```bash
nohup java -jar app.jar &> app.log &
```

查看后台任务：

```bash
jobs
fg %1
bg %1
```

## **8. 服务管理 systemctl（现代 Linux 标配）**

|操作|命令|示例|
|---|---|---|
|启动服务|`systemctl start nginx`||
|停止服务|`systemctl stop nginx`||
|重启服务|`systemctl restart nginx`||
|查看状态|`systemctl status nginx`||
|查看日志|`journalctl -u nginx`||
|开机启动|`systemctl enable nginx`||
|取消启动|`systemctl disable nginx`||
