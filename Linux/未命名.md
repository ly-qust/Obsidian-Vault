# 一、核心概念（一分钟记牢）

- Linux = **内核 + 发行版**（内核由 Linus 维护；发行版把内核、包管理、工具组合起来）。常见发行版：CentOS/RHEL、Ubuntu/Debian、Fedora、Alpine、Arch。
    
- 目标场景：服务器（大多数后端、中间件、数据库都跑在 Linux 上），因此要会**远程连接（SSH）/权限/服务管理/部署**。
    
- 常用远程工具：ssh（命令行）、FinalShell、PuTTY、MobaXterm 等。
    

# 二、目录结构 — 一棵倒挂树（必须记住）

- `/` 根
    
- `/bin` 常用二进制（普通用户）
    
- `/sbin` 系统管理二进制（root）
    
- `/usr` 程序和只读数据（`/usr/bin` `/usr/sbin`）
    
- `/etc` 配置文件（系统/服务配置）
    
- `/var` 运行时会变的文件（日志 `/var/log`， spool）
    
- `/home` 普通用户目录（`/root` 为 root 的家）
    
- `/lib` 共享库（动态链接库）
    
- `/boot` 引导相关文件（kernel、grub）
    
- `/dev` 设备文件（磁盘、终端、网卡）
    
- `/tmp` 临时文件（重启可能清空）  
    （记忆法：把“/etc 配置、/var 日志、/home 用户、/usr 程序”四个关键词记住） 。
    

# 三、Shell 基本技巧（提高效率）

- Tab 自动补全；双按 Tab 列建议。
    
- 上/下箭头浏览历史；`history` 列出历史，`!n` 执行历史第 n 条，`!!` 重复上一条。
    
- 输入与输出重定向：`>` 覆盖写，`>>` 追加，`2>` 错误重定向，`&>` 同时重定向 stdout/stderr。
    
- 管道与组合：`cmd1 | cmd2`、`cmd1 && cmd2`（上一命令成功才执行） 、`cmd1 || cmd2`（上一命令失败才执行）。
    
- 使用 `sudo` 以临时管理员权限运行（记得安全）。
    

# 四、目录与文件常用命令（必会）

- `pwd` — 显示当前目录
    
- `ls` — 列表
    
    - `ls -l`（详细），`ls -a`（显示隐藏文件），`ll` 常被别名为 `ls -l`。
        
- `cd` — 切换目录：`cd ~`（home），`cd -`（返回上一次目录），`cd ..`（上级） 。
    
- `mkdir [-p] dir` — 创建目录（`-p` 递归）
    
- `rm [-rf] name` — 删除（危险！特别注意 `rm -rf /` 或 `rm -rf *`）
    
- `cp [-r] src dst` — 复制（目录需 `-r`）
    
- `mv src dst` — 移动或重命名
    
- **示例**：`cp -r project/ /backup/project_bak/`；`mv foo.txt /tmp/`。
    

# 五、查看与编辑文件（日志 / 配置 常用）

- `cat file` — 直接输出全部（小文件）
    
- `more file` / `less file` — 分页查看（`less` 更灵活，常用）
    
- `head -n N file`、`tail -n N file` — 查看首/尾 N 行；`tail -f file` 实时跟踪日志（调试服务） 。
    
- 文本编辑器：`vim` / `vi`（服务器常见），`nano`（更简单）
    
    - `vim` 三模式：命令模式 / 插入模式 / 底线命令模式（`:wq` 保存退出，`q!` 不保存退出，`/pattern` 查找） 。
        

# 六、查找（文件与内容）

- `find /path -name "*.log"` — 按文件名查找（支持复杂表达式）
    
- `grep -n "pattern" file` — 在文件中查找字符串（`-i` 忽略大小写，`-r` 递归，`-A n` / `-B n` 上下文）
    
- 组合示例：`find /var/log -name "*.log" -exec grep -n "ERROR" {} \;` 或 `grep -r "TODO" /home/user/project`。
    

# 七、权限与用户（必须懂）

- 权限表示法：`rwx rwx rwx` -> `u`（owner）`g`（group）`o`（others）
    
- `ls -l` 看权限（例如 `-rw-r--r--`）
    
- `chmod` 改权限：`chmod 755 file`（777 非常危险）
    
- `chown user:group file` 改所有者/组
    
- `su -` 切换用户（`su - root`），`sudo` 用法（推荐通过 sudo 管理权限） 。
    
- **注意**：避免给敏感文件 777 权限；生产环境首选最小权限原则。
    

# 八、进程与服务管理（运维常用）

- 查看进程：`ps -ef | grep name` / `ps aux`
    
- 杀掉进程：`kill PID`（温和），`kill -9 PID`（强制）
    
- systemd（现代大多数发行版）：
    
    - `systemctl start|stop|restart|status service`
        
    - `systemctl enable|disable service`（开机启动）
        
- 日志：`journalctl -u service`（查看 systemd 管理的服务日志）
    
- 后台运行：`nohup <cmd> &> out.log &`（常用于后台守护运行），切记记录 PID 或使用 systemd unit 来管理。
    

# 九、打包 / 压缩（备份、部署）

- `tar` 常见：
    
    - `tar -cvf a.tar files/`（打包）
        
    - `tar -zcvf a.tar.gz files/`（打包 + gzip 压缩）
        
    - `tar -xvf a.tar` / `tar -zxvf a.tar.gz`（解包/解压）
        
    - 解压到指定目录：`tar -zxvf file.tar.gz -C /path` 。
        

# 十、软件安装（不同发行版）

- RPM 系（RHEL/CentOS）：
    
    - `rpm -qa` 列所有已安装包（可配合 `grep`）
        
    - `rpm -e --nodeps package` 卸载（慎用 `--nodeps`）
        
    - `yum install pkg` / `yum remove pkg`（CentOS7）
        
- DEB 系（Debian/Ubuntu）：
    
    - `dpkg -l`、`apt-get install pkg`、`apt-get update`
        
- 二进制方式：解压后手动配置（例如 JDK、MySQL 的二进制包安装示例）。
    

# 十一、网络与防火墙（常见部署问题）

- 基本网络调试：
    
    - `ip addr` / `ifconfig`（查看网卡）
        
    - `ping host`、`netstat -tulpn`（查看端口占用）、`ss -tulpn`（更现代）
        
- 防火墙（firewalld 示例）：
    
    - `systemctl status firewalld` / `firewall-cmd --state`
        
    - `firewall-cmd --zone=public --add-port=3306/tcp --permanent`（开放端口），`firewall-cmd --reload` （生效）
        
    - `systemctl stop firewalld` 或 `systemctl disable firewalld`（不推荐生产这样永久关闭） 。
        

# 十二、部署 / 常见服务安装要点（实战笔记）

- JDK：上传 tar.gz -> `tar -zxvf` 到 `/usr/local` -> 修改 `/etc/profile` 加 `JAVA_HOME` 与 `PATH` -> `source /etc/profile` -> `java -version` 验证。
    
- MySQL：注意先卸载系统的 MariaDB 冲突包（`rpm -qa | grep mariadb`），解压、移动到 `/usr/local/mysql`，创建 mysql 用户并初始化数据目录，注册为系统服务并开放 3306 端口。
    
- Nginx：安装依赖（pcre zlib openssl）、编译安装（`./configure --prefix=/usr/local/nginx`、`make`、`make install`），常用命令：`sbin/nginx`、`sbin/nginx -s reload`。
    
- 项目部署：打包 jar -> 上传 `/usr/local/app` -> 推荐使用 systemd 管理服务或使用 `nohup java -jar app.jar &> app.log &`（但 systemd 更正规）。
    

# 十三、日志与排查（常见套路）

1. 先看服务状态：`systemctl status xxx`
    
2. 看日志（`journalctl -u xxx` 或 `tail -f /path/to/log`）
    
3. 若端口问题：`ss -tulpn | grep 8080` 或 `netstat -tulpn`
    
4. 查依赖包/版本冲突：`rpm -qa | grep mysql` / `dpkg -l | grep mysql`
    
5. 权限问题：`ls -l` 检查文件/目录权限，`chown/chmod` 调整。
    

# 十四、运维常用小技巧（记住这些会让你省时间）

- 使用 `&> logfile &` + `ps -ef | grep` 找 PID；停止时 `kill PID`。但生产建议写 systemd unit。
    
- 常用 `grep` + `-n` 加行号快速定位日志。
    
- 用 `scp` 或 SFTP/FinalShell 上传文件；使用 `tar` 做批量传输后在服务器解包。
    
- 编写 `systemd` 单元（service 文件）来管理长期运行服务（开机自启、重启策略）。
    
- `crontab -e` 添加定时任务（`*/5 * * * * /path/to/script`） 。
    

# 十五、常见误区 & 安全提示（务必牢记）

- **不要** 在不了解的情况下给文件 `chmod 777`。
    
- `rm -rf` 是有杀伤力的——在脚本中最好加判定或交互确认（或把重要目录设置为只读）。
    
- 生产环境不要用 `root` 长期运行应用，使用专用账号并最小权限。
    
- 开放端口时要配合防火墙策略与安全组（云上），不要直接关防火墙来解决连不上问题（先定位是哪一层阻断）。

# 十六、超浓缩速查表（最重要的命令 — 日常背诵）

- 导航与基础：`pwd`, `ls -al`, `cd`, `mkdir -p`, `rm -rf`（危险）
    
- 文件操作：`cp -r src dst`, `mv src dst`, `cat file`, `less file`
    
- 查看日志：`tail -f file`, `head -n 50 file`
    
- 查找：`find /path -name "pattern"`, `grep -R "text" .`
    
- 权限：`chmod 755 file`, `chown user:group file`
    
- 进程/服务：`ps -ef | grep name`, `kill PID`, `systemctl start/stop/restart/status name`, `journalctl -u name`
    
- 压缩/解压：`tar -zcvf a.tar.gz dir/`, `tar -zxvf a.tar.gz -C /dest`
    
- 网络：`ip addr`, `ss -tulpn`, `ping host`, `curl http://host:port`
    
- 包管理：`yum install pkg`（RHEL/CentOS） / `apt-get install pkg`（Debian/Ubuntu）
    
- 后台运行：`nohup cmd &> out.log &`（短期可用）
    
- 环境变量：在 `/etc/profile` 或 `~/.bashrc` 写 `export VAR=xxx`，然后 `source /etc/profile`。
