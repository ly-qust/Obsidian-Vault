# 操作系统高频自测

> 当前面试主入口：[[操作系统面试精炼笔记/00-操作系统知识地图]]
> 建议先遮住“参考要点”闭答，再用 Java 或 Linux 场景补一个例子。

## 自测题

### 1. 进程和线程有什么区别？

参考要点：进程偏资源隔离和地址空间，线程偏执行和调度；同进程线程共享更多资源，但拥有自己的栈和执行上下文。

### 2. 为什么线程切换通常比进程切换轻量？

参考要点：线程共享地址空间和资源映射，隔离切换工作较少；但仍需保存/恢复上下文，并可能损失缓存局部性。

### 3. Java 平台线程、OS 线程和虚拟线程如何对应？

参考要点：传统 Java 平台线程通常由 JVM 封装 OS 线程；Java21 虚拟线程由 JVM 调度到平台线程，不是取消 OS 线程。

### 4. 进程的 Ready、Running、Blocked/Waiting、Terminated 如何转换？

参考要点：创建后就绪，获得 CPU 执行，等待 I/O/资源时阻塞，条件满足后回到就绪，任务结束进入终止；教材状态命名可能不同。

### 5. 常见 IPC 有哪些？

参考要点：管道、消息队列、共享内存、信号、Socket；比较时说清数据形态、亲缘关系、复制成本和是否需要额外同步。

### 6. 共享内存为什么快，为什么还需要信号量？

参考要点：减少进程间数据复制，但多个执行单元仍可能同时读改写，必须额外保证顺序和一致性。

### 7. 用户态和内核态的区别是什么？

参考要点：权限和可执行操作范围不同；应用访问文件、设备等特权资源要通过受控的系统调用进入内核。

### 8. 系统调用和普通函数调用有什么区别？

参考要点：系统调用跨越用户/内核权限边界，由内核校验参数并执行特权操作；普通函数通常停留在用户态。

### 9. 文件描述符是什么？

参考要点：进程打开文件、管道、Socket、设备等内核对象后得到的整数句柄；0/1/2 通常对应标准输入/输出/错误。

### 10. FD 泄漏如何排查？

参考要点：看 `Too many open files`、`/proc/<pid>/fd`、`lsof` 和 `ulimit -n`，再检查连接、文件和异常路径是否正确关闭。

### 11. 虚拟内存解决什么问题？

参考要点：提供进程隔离、地址抽象和权限保护；不是凭空增加物理内存，也不等于 Swap。

### 12. 页表和 TLB 分别做什么？

参考要点：页表保存虚拟页到物理页的映射和权限，TLB 缓存热点页表项；TLB 未命中不等于缺页。

### 13. 缺页一定表示程序出错吗？

参考要点：不一定；按需分配、文件映射和换入都可能是合法缺页，非法地址或权限错误才会导致进程异常。

### 14. JVM 堆和操作系统虚拟内存是什么关系？

参考要点：JVM 堆是进程虚拟地址空间中的逻辑区域；GC 管理对象，页表/缺页由 OS 和硬件管理，不能混为一谈。

### 15. 互斥和同步有什么区别？

参考要点：互斥保证同一时刻只有一个执行单元进入临界区；同步约束事件条件和执行顺序。

### 16. 信号量和互斥锁有什么区别？

参考要点：互斥锁强调 0/1 和所有权；计数信号量表达多个可用许可，适合连接池、缓冲区和并发上限。

### 17. 死锁的四个必要条件是什么？

参考要点：互斥、占有且等待、不可剥夺、循环等待；破坏任一条件即可预防该类死锁。

### 18. 阻塞和非阻塞有什么区别？

参考要点：阻塞调用在条件不满足时暂不返回；非阻塞调用立即返回当前结果，可能要求调用方重试、轮询或配合事件机制。

### 19. 同步 I/O 和异步 I/O 怎么区分？

参考要点：同步强调调用方要参与等待或接收结果；异步强调提交后由系统/运行时在完成时通知，不能简单等同于阻塞/非阻塞。

### 20. 文件系统中目录、文件、inode 和 FD 如何串起来？

参考要点：目录把名字映射到文件对象/inode，inode 保存元数据和数据定位信息；进程 `open` 后得到 FD，FD 指向内核打开文件对象，再关联文件实体。

## 角色化追问

- Java开发：把第 3、9、14、18 题分别联系平台/虚拟线程、连接池、JVM OOM 和 Java I/O。
- AI应用：把第 9、11、14、18 题联系模型服务连接、文件/模型加载、进程内存和高并发请求等待。
- 运维：把第 4、9、10、13、17 题联系 `ps`、`top`、`/proc`、`lsof`、日志和线程 dump。
- 央国企计算机岗：优先完整说出定义、因果链、边界和一个典型例子，不追求内核源码细节。

## 易错点总览

- 不把“线程是调度单位”说成所有系统都只有这一种调度对象。
- 不把 TLB 未命中、缺页、OOM 和 Swap 当成同一件事。
- 不把同步/异步直接等同于阻塞/非阻塞，也不把 FD 说成文件本体。
- 不把 Java 锁、线程池或 GC 的实现细节当作本篇 OS 主干答案。
