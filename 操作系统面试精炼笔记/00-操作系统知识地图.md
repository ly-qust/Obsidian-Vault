> [!important] 一句话结论
> 操作系统面试主线是：进程提供资源隔离，线程承载执行，系统调用连接用户态与内核态，虚拟内存提供地址空间，同步与 I/O 决定并发行为。

## 推荐复习路径

```text
进程/线程与执行载体
→ 状态转换与 IPC
→ 用户态/内核态与系统调用
→ 虚拟地址/页表/TLB/缺页
→ 同步互斥/信号量/死锁
→ 阻塞非阻塞/同步异步/FD/文件系统（见 03）
→ [[操作系统面试精炼笔记/07-操作系统高频自测]]
```

## 一条因果链

```text
进程隔离资源
→ 线程在进程内共享资源并执行
→ 调度切换保存/恢复执行上下文
→ 访问特权资源必须通过系统调用进入内核
→ 地址转换依赖页表与 TLB，未映射时触发缺页
→ 共享资源需要同步互斥，错误的等待顺序可能死锁
→ I/O 是否占用执行载体取决于阻塞/非阻塞与同步/异步语义
```

## Java / Linux 关联

- Java 传统平台线程通常映射到操作系统线程；Java21 虚拟线程由 JVM 调度到载体线程，详细内容回看 [[java知识/java线程与内核线程的区别]]、[[java知识/Java21虚拟线程]]。
- JVM 的堆、栈、元空间是 JVM 运行时概念，最终仍建立在进程虚拟地址空间之上；GC 不等于操作系统分页，回看 [[java八股文/Java后端面试精炼笔记/03-JVM内存-GC与排查]]。
- Linux 运维排查优先会看进程、线程、资源和服务：`ps`、`top`、`/proc`、`systemctl`、`journalctl`，命令入口见 [[Linux/命令操作]]、[[Linux/未命名]]。
- 不在本地图重复 Java 的 volatile、CAS、锁实现和线程池参数；这些属于并发工具选型，回看 [[java八股文/Java后端面试精炼笔记/02-并发工具选型]]。

## 范围边界

本地图面向面试解释和工程排查，不展开 408 教材式证明、页面置换算法计算、复杂 CPU 调度算法、内核源码和具体文件系统实现源码。

## 地图级易错点

- OS 的进程/线程状态与 Java `Thread.State` 不是逐项同名映射。
- TLB 未命中不等于缺页，JVM 堆也不等于物理内存或 Swap。
- 阻塞/非阻塞和同步/异步是两组不同维度；FD 是句柄，不是文件内容。
- 同步互斥解决共享资源协作，不等于复制 Java 并发工具实现细节。

## 高频追问

1. Java21 虚拟线程改变了什么、没有改变什么？——改变任务与平台线程的调度方式，没有取消 OS 线程、FD 或下游容量限制。
2. 为什么一次 I/O 可能涉及用户态、内核态、FD、页缓存和调度？——应用通过系统调用访问内核对象，内核再根据缓存和设备状态决定是否等待。
3. 如何把 OS 知识落到排障？——从进程/线程、内存、FD、锁等待和 I/O 等待五条线索观察，再用日志和线程栈验证因果链。

## 60 秒总回答

> 进程是资源隔离和分配的基本边界，线程是进程内的执行单元；线程切换要保存和恢复上下文。应用访问文件、网络和其他特权能力要通过系统调用在用户态与内核态之间切换。每个进程使用虚拟地址空间，地址转换依赖页表和 TLB，未命中映射会触发缺页处理。多个执行单元共享资源时要用互斥和同步，信号量可以控制并发或表示资源，错误的资源顺序会造成死锁。I/O 还要区分阻塞/非阻塞与同步/异步，文件描述符是用户程序访问内核对象的句柄。
