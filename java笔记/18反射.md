## 一、反射的核心概念（笔记18.1节）

### 1. 什么是反射（笔记18.1.1节）

- **定义**：反射是Java提供的一种动态编程机制，允许程序在**运行时**获取类的结构信息（如属性、方法、构造器），并动态操作类或对象（如创建对象、调用方法、修改属性），无需在编译时确定具体类。
    
- **核心思想**：“反向探知”——正常编程是“编译时确定类→创建对象→调用方法”，反射是“运行时获取类信息→动态操作”。
    
- **反射的必要性（实战场景）**：
    
    1. 框架开发：Spring的IOC容器通过反射创建Bean对象、MyBatis通过反射映射数据库字段与实体类属性。
        
    2. 动态调用：如根据配置文件（如XML）中的类名，动态创建对象并调用方法（无需修改代码）。
        
    3. 通用工具开发：如通用对象拷贝工具、JSON序列化工具（需动态获取对象属性）。
        

### 2. 反射的核心API（笔记18.1.2节）

Java通过`java.lang.reflect`包提供反射功能，核心类：

- `Class`：类的“元对象”，代表一个类的结构信息（唯一对应一个加载到JVM的类）。
    
- `Field`：代表类的属性（成员变量），可动态获取/修改属性值。
    
- `Method`：代表类的方法，可动态调用方法。
    
- `Constructor`：代表类的构造器，可动态创建对象。
    
- `Modifier`：解析类/属性/方法的访问修饰符（如public、private）。
    

### 3. 反射的优缺点（笔记18.1.3节）

|优点|缺点|
|---|---|
|灵活性高（动态操作类/对象）|性能较低（比直接调用慢，需解析类信息）|
|通用性强（适配任意类）|安全性降低（可突破访问修饰符限制）|
|框架开发必备（解耦）|代码可读性差（动态调用逻辑复杂）|

## 二、Class类与类加载（笔记18.2节，核心基础）

### 1. Class类的核心作用（笔记18.2.1节）

- `Class`类是反射的“入口”，每个类被JVM加载后，都会生成一个唯一的`Class`对象（存储类的结构信息：属性、方法、构造器、父类、接口等）。
    
- 任何对象都可以通过`getClass()`方法获取其对应的`Class`对象，同一个类的所有对象共享同一个`Class`对象。
    

### 2. 获取Class对象的3种方式（笔记18.2.2节，高频考点）

```java
import com.hspedu.reflection.Student;

public class ClassGetDemo {
    public static void main(String[] args) throws ClassNotFoundException {
        // 方式1：通过对象.getClass()（需先创建对象，最常用）
        Student student = new Student();
        Class<?> clazz1 = student.getClass();
        System.out.println("方式1：" + clazz1.getName());

        // 方式2：通过类名.class（无需创建对象，编译时确定）
        Class<?> clazz2 = Student.class;
        System.out.println("方式2：" + clazz2.getName());
        System.out.println("clazz1 == clazz2：" + (clazz1 == clazz2)); // true

        // 方式3：通过Class.forName("类的全限定名")（动态加载，运行时确定，框架常用）
        Class<?> clazz3 = Class.forName("com.hspedu.reflection.Student");
        System.out.println("方式3：" + clazz3.getName());
        System.out.println("clazz1 == clazz3：" + (clazz1 == clazz3)); // true
    }
}

// 测试用实体类
class Student {
    private String name;
    private int age;
    public String gender;

    public Student() {}
    public Student(String name, int age) { this.name = name; this.age = age; }

    public void study() { System.out.println(name + "正在学习"); }
    private void eat(String food) { System.out.println(name + "正在吃" + food); }
}
```

### 3. 类加载的时机（笔记18.2.3节）

JVM在以下时机加载类并生成`Class`对象：

1. 创建类的对象时（如`new Student()`）。
    
2. 调用类的静态属性/方法时（如`Student.staticMethod()`）。
    
3. 通过`Class.forName()`动态加载时。
    
4. 加载子类时，父类会被优先加载。
    
5. 用`java.exe`命令执行类时（加载主类）。
    

### 4. Class类的常用方法（笔记18.2.4节）

```java
public class ClassMethodDemo {
    public static void main(String[] args) throws ClassNotFoundException {
        Class<?> clazz = Class.forName("com.hspedu.reflection.Student");

        // 1. 获取类的基本信息
        System.out.println("类名：" + clazz.getName());
        System.out.println("简单类名：" + clazz.getSimpleName());
        System.out.println("父类：" + clazz.getSuperclass().getName());
        System.out.println("是否为接口：" + clazz.isInterface());

        // 2. 获取类的加载器
        System.out.println("类加载器：" + clazz.getClassLoader());

        // 3. 创建对象（调用无参构造器）
        try {
            Student student = (Student) clazz.newInstance();
            student.gender = "男";
            System.out.println("创建的对象性别：" + student.gender);
        } catch (InstantiationException | IllegalAccessException e) {
            e.printStackTrace();
        }
    }
}
```

## 三、反射获取类的结构信息（笔记18.3节，核心重点）

通过反射可获取类的所有结构信息（属性、方法、构造器、注解、接口等）。

### 1. 获取属性（Field）（笔记18.3.1节）

#### 核心方法：

- `getFields()`：获取所有**public**属性（包括父类）。
    
- `getDeclaredFields()`：获取当前类的**所有**属性（public/private/protected/默认），不包括父类。
    
- `getField(String name)`：获取指定名称的public属性。
    
- `getDeclaredField(String name)`：获取指定名称的当前类属性（任意修饰符）。
    

#### 实战案例：

```java
import java.lang.reflect.Field;

public class FieldReflectionDemo {
    public static void main(String[] args) throws Exception {
        Class<?> clazz = Class.forName("com.hspedu.reflection.Student");

        // 所有public属性
        Field[] publicFields = clazz.getFields();
        for (Field field : publicFields) System.out.println(field.getName());

        // 当前类所有属性
        Field[] allFields = clazz.getDeclaredFields();
        for (Field field : allFields) System.out.println(field.getName() + " 修饰符：" + java.lang.reflect.Modifier.toString(field.getModifiers()));

        // 修改private属性
        Student student = new Student("张三", 20);
        Field nameField = clazz.getDeclaredField("name");
        nameField.setAccessible(true);
        nameField.set(student, "李四");
        System.out.println(nameField.get(student));

        // 修改public属性
        Field genderField = clazz.getField("gender");
        genderField.set(student, "女");
        System.out.println(student.gender);
    }
}
```

### 2. 获取方法（Method）（笔记18.3.2节）

#### 核心方法：

- `getMethods()`：获取所有**public**方法（包括父类）。
    
- `getDeclaredMethods()`：获取当前类的**所有**方法（任意修饰符）。
    
- `getMethod(String name, Class<?>... parameterTypes)`：获取指定名称和参数类型的public方法。
    
- `getDeclaredMethod(String name, Class<?>... parameterTypes)`：获取指定名称和参数类型的当前类方法（任意修饰符）。
    

#### 实战案例：

```java
import java.lang.reflect.Method;

public class MethodReflectionDemo {
    public static void main(String[] args) throws Exception {
        Class<?> clazz = Class.forName("com.hspedu.reflection.Student");
        Student student = new Student("张三", 20);

        // 获取所有public方法
        Method[] publicMethods = clazz.getMethods();
        for (Method method : publicMethods) System.out.println(method.getName());

        // 当前类所有方法
        Method[] allMethods = clazz.getDeclaredMethods();
        for (Method method : allMethods) System.out.println(method.getName() + " 修饰符：" + java.lang.reflect.Modifier.toString(method.getModifiers()));

        // 调用public方法study()
        Method studyMethod = clazz.getMethod("study");
        studyMethod.invoke(student);

        // 调用private方法eat(String)
        Method eatMethod = clazz.getDeclaredMethod("eat", String.class);
        eatMethod.setAccessible(true);
        eatMethod.invoke(student, "米饭");
    }
}
```

### 3. 获取构造器（Constructor）（笔记18.3.3节）

#### 核心方法：

- `getConstructors()`：获取所有**public**构造器。
    
- `getDeclaredConstructors()`：获取当前类的**所有**构造器。
    
- `getConstructor(Class<?>... parameterTypes)`：获取指定参数类型的public构造器。
    
- `getDeclaredConstructor(Class<?>... parameterTypes)`：获取指定参数类型的构造器。
    

#### 实战案例：

```java
import java.lang.reflect.Constructor;

public class ConstructorReflectionDemo {
    public static void main(String[] args) throws Exception {
        Class<?> clazz = Class.forName("com.hspedu.reflection.Student");

        // 所有构造器
        Constructor<?>[] constructors = clazz.getDeclaredConstructors();
        for (Constructor<?> constructor : constructors) System.out.println(constructor.getName());

        // 无参构造器创建对象
        Constructor<?> noArgConstructor = clazz.getConstructor();
        Student student1 = (Student) noArgConstructor.newInstance();
        student1.gender = "男";

        // 带参构造器创建对象
        Constructor<?> argConstructor = clazz.getConstructor(String.class, int.class);
        Student student2 = (Student) argConstructor.newInstance("李四", 22);
        Method studyMethod = clazz.getMethod("study");
        studyMethod.invoke(student2);
    }
}
```

## 四、反射的实战应用（笔记18.4节）

### 1. 通用对象拷贝工具（反射实现）

```java
import java.lang.reflect.Field;

public class ObjectCopyUtil {
    public static <T> T copyObject(T source, Class<T> targetClass) {
        T target = null;
        try {
            target = targetClass.newInstance();
            Field[] fields = source.getClass().getDeclaredFields();
            for (Field field : fields) {
                field.setAccessible(true);
                Object value = field.get(source);
                Field targetField = targetClass.getDeclaredField(field.getName());
                targetField.setAccessible(true);
                targetField.set(target, value);
            }
        } catch (Exception e) { e.printStackTrace(); }
        return target;
    }

    public static void main(String[] args) {
        Student source = new Student("张三", 20);
        source.gender = "男";
        Student target = copyObject(source, Student.class);
        System.out.println(target.getName());
        System.out.println(target.getAge());
        System.out.println(target.gender);
    }
}

class Student {
    private String name;
    private int age;
    public String gender;
    public Student() {}
    public Student(String name, int age) { this.name = name; this.age = age; }
    public String getName() { return name; }
    public int getAge() { return age; }
}
```

### 2. 根据配置文件动态创建对象

```java
import java.io.InputStream;
import java.util.Properties;
import java.lang.reflect.Method;

public class DynamicObjectDemo {
    public static void main(String[] args) throws Exception {
        Properties prop = new Properties();
        InputStream is = DynamicObjectDemo.class.getClassLoader().getResourceAsStream("config.properties");
        prop.load(is);

        String className = prop.getProperty("className");
        String methodName = prop.getProperty("methodName");

        Class<?> clazz = Class.forName(className);
        Object obj = clazz.newInstance();
        Method method = clazz.getMethod(methodName);
        method.invoke(obj);
    }
}

// config.properties
// className=com.hspedu.reflection.Student
// methodName=study
```

### 3. 反射与注解结合

```java
import java.lang.annotation.*;
import java.lang.reflect.Field;

@Target(ElementType.FIELD)
@Retention(RetentionPolicy.RUNTIME)
@interface MyColumn { String value(); }

class User {
    @MyColumn("user_name") private String name;
    @MyColumn("user_age") private int age;
}

public class AnnotationReflectionDemo {
    public static void main(String[] args) throws Exception {
        Class<?> clazz = Class.forName("com.hspedu.reflection.User");
        Field[] fields = clazz.getDeclaredFields();
        for (Field field : fields) {
            if (field.isAnnotationPresent(MyColumn.class)) {
                MyColumn myColumn = field.getAnnotation(MyColumn.class);
                System.out.println(field.getName() + " → " + myColumn.value());
            }
        }
    }
}
```

## 五、反射的避坑点（笔记18.5节核心）

1. **访问权限问题**：private/protected需`setAccessible(true)`，安全管理器可能限制。
    
2. **性能问题**：反射比直接调用慢，高频调用需缓存`Class`/`Field`/`Method`对象。
    
3. **构造器问题**：`Class.newInstance()`需无参构造器，带参构造器用`Constructor.newInstance()`。
    
4. **泛型擦除问题**：无法获取泛型具体类型，编译时会擦除。
    
5. **异常处理**：多为受检异常，需捕获或声明`throws`。
    
6. **类加载问题**：`Class.forName()`需全限定名。
