## 一、IO流概述（笔记15.1节）

### 1. 核心概念（笔记15.1.1节）

- **定义**：IO流（输入/输出流）是Java中用于处理设备间数据传输的抽象机制，通过“流”（Stream）的形式将数据从一个设备（如内存、磁盘、网络）传输到另一个设备。
    
- **核心作用**：
    
    1. 数据持久化：将内存中的数据写入磁盘文件（如保存配置、日志）。
        
    2. 数据读取：从磁盘/网络读取数据到内存（如读取配置文件、读取网络请求数据）。
        
    3. 设备间通信：如网络编程中客户端与服务器的数据传输。
        
- **IO流的本质**：流是“数据的有序序列”，传输过程中可分为“输入”（数据进入内存）和“输出”（数据离开内存），且流操作后必须关闭（释放系统资源）。
    

### 2. IO流的分类（笔记15.1.2节核心，高频考点）

Java IO流体系复杂，核心分类维度有3个，需重点掌握：

|分类维度|具体类别|核心特点|典型场景|
|---|---|---|---|
|按数据流向|输入流（InputStream/Reader）|数据从外部设备→内存（如读取文件到内存）|读取配置文件|
||输出流（OutputStream/Writer）|数据从内存→外部设备（如写入数据到文件）|保存用户数据、写日志|
|按数据类型|字节流（InputStream/OutputStream）|传输二进制数据（任意文件类型：图片、视频、文本、exe），单位为“字节（byte）”|读取图片、下载文件|
||字符流（Reader/Writer）|传输字符数据（仅文本文件），单位为“字符（char）”，需考虑编码（如UTF-8、GBK）|读取文本文件、写日志文本|
|按流的角色|节点流（低级流）|直接连接数据源/目的地（如文件、网络），直接操作数据|FileInputStream（读文件）|
||处理流（高级流）|包装在节点流/其他处理流之上，增强功能（如缓冲、转换、序列化）|BufferedInputStream（缓冲）|

**IO流体系结构图（韩顺平笔记简化版）**：

```
IO流体系
├─ 字节流（处理所有文件类型）
│  ├─ 输入字节流（InputStream）
│  │  ├─ 节点流：FileInputStream（文件输入）、ByteArrayInputStream（字节数组输入）
│  │  └─ 处理流：BufferedInputStream（缓冲输入）、DataInputStream（数据输入）、ObjectInputStream（对象输入）
│  └─ 输出字节流（OutputStream）
│     ├─ 节点流：FileOutputStream（文件输出）、ByteArrayOutputStream（字节数组输出）
│     └─ 处理流：BufferedOutputStream（缓冲输出）、DataOutputStream（数据输出）、ObjectOutputStream（对象输出）
└─ 字符流（仅处理文本文件）
   ├─ 输入字符流（Reader）
   │  ├─ 节点流：FileReader（文件字符输入）、CharArrayReader（字符数组输入）
   │  └─ 处理流：BufferedReader（缓冲字符输入）、InputStreamReader（字节→字符转换输入）
   └─ 输出字符流（Writer）
      ├─ 节点流：FileWriter（文件字符输出）、CharArrayWriter（字符数组输出）
      └─ 处理流：BufferedWriter（缓冲字符输出）、OutputStreamWriter（字符→字节转换输出）
```

### 3. 核心注意事项（笔记15.1.3节）

- **资源关闭**：流操作会占用系统资源（如文件句柄），必须在使用后关闭（推荐用`try-with-resources`自动关闭，JDK7+）。
    
- **编码问题**：字符流需指定编码（如UTF-8），避免中文乱码；字节流直接传输二进制，无编码问题。
    
- **异常处理**：IO操作可能抛出`IOException`（编译时异常），必须捕获或声明`throws`。
    
- **文件路径**：操作文件时需指定正确路径（绝对路径：`D:/test.txt`；相对路径：`test.txt`，相对于项目根目录）。

## 二、字节流（核心基础，笔记15.2节）

字节流是IO流的基础，可处理任意文件类型（文本、图片、视频等），核心抽象类为`InputStream`（输入）和`OutputStream`（输出），常用实现类为文件相关的节点流。

### 1. 输入字节流（InputStream）—— 读取数据到内存

#### （1）核心方法（所有字节输入流通用）

- `int read()`：读取1个字节，返回字节值（0-255），到达文件末尾返回`-1`。
    
- `int read(byte[] b)`：读取多个字节到字节数组`b`，返回实际读取的字节数，末尾返回`-1`（推荐，效率高于单字节读取）。
    
- `void close()`：关闭流，释放资源。
    

#### （2）FileInputStream（文件输入字节流，节点流）实战

```java
import java.io.FileInputStream;
import java.io.IOException;

public class FileInputStreamDemo {
    public static void main(String[] args) {
        FileInputStream fis = null;
        try {
            fis = new FileInputStream("test.txt");
            byte[] buffer = new byte[1024];
            int len;
            StringBuilder sb = new StringBuilder();
            while ((len = fis.read(buffer)) != -1) {
                sb.append(new String(buffer, 0, len, "UTF-8"));
            }
            System.out.println("文件内容：" + sb.toString());
        } catch (IOException e) {
            e.printStackTrace();
        } finally {
            try {
                if (fis != null) {
                    fis.close();
                }
            } catch (IOException e) {
                e.printStackTrace();
            }
        }

        try (FileInputStream fis2 = new FileInputStream("test.txt")) {
            byte[] buffer = new byte[1024];
            int len;
            while ((len = fis2.read(buffer)) != -1) {
                System.out.println(new String(buffer, 0, len, "UTF-8"));
            }
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
}
```

### 2. 输出字节流（OutputStream）—— 写入数据到外部设备

#### （1）核心方法（所有字节输出流通用）

- `void write(int b)`：写入1个字节（仅取int的低8位）。
    
- `void write(byte[] b)`：写入字节数组`b`的所有字节。
    
- `void write(byte[] b, int off, int len)`：写入字节数组`b`从索引`off`开始的`len`个字节。
    
- `void flush()`：刷新流，将缓冲区数据强制写入目的地（缓冲流必须调用）。
    
- `void close()`：关闭流（关闭前会自动刷新）。
    

#### （2）FileOutputStream（文件输出字节流，节点流）实战

```java
import java.io.FileOutputStream;
import java.io.IOException;

public class FileOutputStreamDemo {
    public static void main(String[] args) {
        try (FileOutputStream fos = new FileOutputStream("output.txt", true)) {
            String content = "Hello IO流！\n这是字节流写入的内容。";
            byte[] data = content.getBytes("UTF-8");
            fos.write(data);
            fos.flush();
            System.out.println("写入成功！");
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
}
```

#### （3）字节流复制文件（实战核心：读取+写入结合）

```java
import java.io.FileInputStream;
import java.io.FileOutputStream;
import java.io.IOException;

public class FileCopyDemo {
    public static void main(String[] args) {
        String srcPath = "D:/test.jpg";
        String destPath = "D:/test_copy.jpg";
        long start = System.currentTimeMillis();
        try (FileInputStream fis = new FileInputStream(srcPath);
             FileOutputStream fos = new FileOutputStream(destPath)) {
            byte[] buffer = new byte[4096];
            int len;
            while ((len = fis.read(buffer)) != -1) {
                fos.write(buffer, 0, len);
            }
            long end = System.currentTimeMillis();
            System.out.println("文件复制成功！耗时：" + (end - start) + "ms");
        } catch (IOException e) {
            e.printStackTrace();
            System.out.println("文件复制失败！");
        }
    }
}
```

## 三、字符流（文本文件专用，笔记15.3节）

### 1. 核心特点（与字节流的区别）

- **编码支持**：字符流读取时会将字节按指定编码（如UTF-8）转为字符，写入时将字符转为字节，天然解决中文乱码。
    
- **适用场景**：仅文本文件（`.txt`、`.md`、`.java`等），不能处理图片、视频等二进制文件。
    
- **核心实现类**：文件相关节点流`FileReader`/`FileWriter`，缓冲字符流`BufferedReader`/`BufferedWriter`（推荐，效率高且支持按行读取）。
    

### 2. FileReader（文件输入字符流）实战

```java
import java.io.FileReader;
import java.io.IOException;

public class FileReaderDemo {
    public static void main(String[] args) {
        try (FileReader fr = new FileReader("test.txt")) {
            char[] buffer = new char[1024];
            int len;
            StringBuilder sb = new StringBuilder();
            while ((len = fr.read(buffer)) != -1) {
                sb.append(buffer, 0, len);
            }
            System.out.println("文本内容：" + sb.toString());
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
}
```

### 3. FileWriter（文件输出字符流）实战

```java
import java.io.FileWriter;
import java.io.IOException;

public class FileWriterDemo {
    public static void main(String[] args) {
        try (FileWriter fw = new FileWriter("output.txt", true)) {
            String content = "Hello 字符流！\n这是中文内容，不会乱码。";
            fw.write(content);
            fw.write("\n追加一行内容。");
            fw.flush();
            System.out.println("写入成功！");
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
}
```

### 4. 缓冲字符流（BufferedReader/BufferedWriter）—— 高效文本处理

```java
import java.io.BufferedReader;
import java.io.BufferedWriter;
import java.io.FileReader;
import java.io.FileWriter;
import java.io.IOException;

public class BufferedCharStreamDemo {
    public static void main(String[] args) {
        try (BufferedReader br = new BufferedReader(new FileReader("test.txt"));
             BufferedWriter bw = new BufferedWriter(new FileWriter("output_buffered.txt"))) {
            String line;
            int lineNum = 0;
            while ((line = br.readLine()) != null) {
                lineNum++;
                bw.write(lineNum + "：" + line);
                bw.newLine();
            }
            bw.flush();
            System.out.println("处理完成！共" + lineNum + "行");
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
}
```

## 四、转换流（字节流→字符流，笔记15.4节）

```java
import java.io.BufferedReader;
import java.io.BufferedWriter;
import java.io.FileInputStream;
import java.io.FileOutputStream;
import java.io.IOException;
import java.io.InputStreamReader;
import java.io.OutputStreamWriter;

public class ConvertStreamDemo {
    public static void main(String[] args) {
        try (BufferedReader br = new BufferedReader(
                 new InputStreamReader(new FileInputStream("utf8_file.txt"), "UTF-8"));
             BufferedWriter bw = new BufferedWriter(
                 new OutputStreamWriter(new FileOutputStream("gbk_file.txt"), "GBK"))) {
            String line;
            while ((line = br.readLine()) != null) {
                bw.write(line);
                bw.newLine();
            }
            bw.flush();
            System.out.println("UTF-8文件转为GBK文件成功！");
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
}
```

## 五、对象流（序列化与反序列化，笔记15.5节）

### 1. 核心概念

- **序列化**：将Java对象转为字节序列，写入磁盘/网络。
    
- **反序列化**：将字节序列恢复为Java对象。
    
- **核心类**：`ObjectOutputStream`、`ObjectInputStream`。
    
- **必须条件**：对象必须实现`Serializable`接口。
    

### 2. 序列化与反序列化实战

#### （1）定义可序列化对象类

```java
import java.io.Serializable;
import java.util.Date;

class User implements Serializable {
    private static final long serialVersionUID = 1L;
    private String username;
    private transient String password;
    private int age;
    private Date registerTime;

    public User(String username, String password, int age) {
        this.username = username;
        this.password = password;
        this.age = age;
        this.registerTime = new Date();
    }

    @Override
    public String toString() {
        return "User{" +
                "username='" + username + '\'' +
                ", password='" + password + '\'' +
                ", age=" + age +
                ", registerTime=" + registerTime +
                '}';
    }
}
```

#### （2）对象流实战

```java
import java.io.FileInputStream;
import java.io.FileOutputStream;
import java.io.IOException;
import java.io.ObjectInputStream;
import java.io.ObjectOutputStream;

public class ObjectStreamDemo {
    public static void main(String[] args) {
        User user = new User("zhangsan", "123456", 20);
        try (ObjectOutputStream oos = new ObjectOutputStream(new FileOutputStream("user.ser"))) {
            oos.writeObject(user);
            System.out.println("对象序列化成功！");
        } catch (IOException e) {
            e.printStackTrace();
        }

        try (ObjectInputStream ois = new ObjectInputStream(new FileInputStream("user.ser"))) {
            User deserializedUser = (User) ois.readObject();
            System.out.println("反序列化得到的对象：" + deserializedUser);
        } catch (IOException | ClassNotFoundException e) {
            e.printStackTrace();
        }
    }
}
```

#### （3）注意事项

- `transient`关键字：不参与序列化。
    
- `serialVersionUID`：显式指定，避免类结构变化导致反序列化失败。
    
- 静态属性不序列化。
    
- 父类序列化规则：父类未实现Serializable，子类仅序列化子类属性。

## 六、文件操作工具类（笔记15.6节）

```java
import java.io.File;
import java.io.IOException;

public class FileDemo {
    public static void main(String[] args) throws IOException {
        File file = new File("test_file.txt");
        File dir = new File("test_dir");

        if (!file.exists()) {
            boolean created = file.createNewFile();
            System.out.println("文件创建成功？" + created);
        }
        System.out.println("文件大小（字节）：" + file.length());
        System.out.println("文件绝对路径：" + file.getAbsolutePath());
        System.out.println("是否为文件：" + file.isFile());

        if (!dir.exists()) {
            boolean mkdir = dir.mkdir();
            System.out.println("目录创建成功？" + mkdir);
        }
        System.out.println("是否为目录：" + dir.isDirectory());

        if (dir.isDirectory()) {
            File[] files = dir.listFiles();
            if (files != null) {
                for (File f : files) {
                    System.out.println(f.getName() + "：" + (f.isFile() ? "文件" : "目录"));
                }
            }
        }
    }
}
```

## 七、IO流性能优化与避坑点（笔记15.7节核心）

### 1. 性能优化技巧

- 使用缓冲流（减少IO次数）
    
- 合理设置缓冲区（推荐4KB/8KB）
    
- 批量读写（避免单字节/单字符操作）
    
- 及时关闭流（try-with-resources）
    

### 2. 常见避坑点

- 中文乱码：字节流需指定编码，字符流优先转换流
    

指定编码

- 流关闭顺序：关闭外层流即可
    
- 文件路径错误：相对路径相对于项目根目录
    
- 序列化失败：未实现Serializable或未指定serialVersionUID，或对象包含不可序列化属性
