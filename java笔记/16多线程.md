## 一、多线程基础概念（笔记16.1节）

### 1. 核心概念（笔记16.1.1-16.1.2节）

- **进程（Process）**：操作系统中正在运行的程序（如Chrome浏览器、Java.exe），是资源分配的最小单位（拥有独立的内存空间、CPU资源）。
    
- **线程（Thread）**：进程内部的执行单元（如Chrome的一个标签页、Java程序中的一个任务），是CPU调度的最小单位，共享进程的内存空间（如堆、方法区），仅拥有独立的栈和程序计数器。
    
- **多线程的优势**：
    
    1. 提高程序效率（如一边下载文件一边播放音乐，并行处理任务）。
        
    2. 充分利用CPU资源（单线程时CPU可能空闲，多线程可让CPU同时处理多个任务）。
        
    3. 实现异步操作（如用户点击按钮后，后台线程处理数据，主线程不阻塞）。
        
- **线程与进程的区别（高频考点）**：
    
    |对比维度|进程|线程|
    |---|---|---|
    |资源分配|独立资源（内存、CPU）|共享进程资源，仅独立栈和程序计数器|
    |调度单位|操作系统调度进程|CPU调度线程（更轻量）|
    |开销|创建、销毁开销大|创建、销毁开销小（轻量级）|
    |通信方式|复杂（如管道、Socket）|简单（直接共享内存）|
    

### 2. 线程的状态（生命周期，笔记16.1.3节核心）

Java线程有6种状态，由`Thread.State`枚举定义，状态转换是高频考点：

1. **新建状态（New）**：线程对象创建后（如`new Thread()`），未调用`start()`。
    
2. **就绪状态（Runnable）**：调用`start()`后，线程等待CPU调度（具备运行条件，但未获得CPU）。
    
3. **运行状态（Running）**：CPU分配时间片，线程执行`run()`方法。
    
4. **阻塞状态（Blocked）**：线程暂时失去CPU使用权（如等待锁、等待IO），阻塞解除后回到就绪状态。
    
5. **等待状态（Waiting）**：线程无限期等待（如`wait()`无参方法），需其他线程唤醒（如`notify()`）。
    
6. **超时等待状态（Timed Waiting）**：线程限时等待（如`sleep(1000)`、`wait(1000)`），时间到后自动唤醒。
    
7. **终止状态（Terminated）**：`run()`方法执行完毕或线程被中断（`interrupt()`），线程生命周期结束。
    

**状态转换示意图（韩顺平笔记简化版）**：  
`New` → `Runnable`（start()）→ `Running`（CPU调度）→ `Blocked/Waiting/Timed Waiting`（阻塞/等待）→ `Runnable`（阻塞解除/唤醒）→ `Terminated`（任务完成）。

## 二、线程的创建方式（笔记16.2节，核心重点）

Java提供3种线程创建方式，笔记中明确要求掌握前两种，第三种（Callable）为进阶内容：

### 1. 方式1：继承Thread类（笔记16.2.1节）

- **核心步骤**：
    
    1. 自定义类继承`java.lang.Thread`类。
        
    2. 重写`run()`方法（线程执行的任务逻辑）。
        
    3. 创建线程对象，调用`start()`方法启动线程（不能直接调用`run()`，否则为普通方法调用）。
        
- **实战案例**：
    

```java
// 1. 自定义线程类（继承Thread）
class MyThread extends Thread {
    // 线程名称（可选，用于区分线程）
    public MyThread(String name) {
        super(name); // 调用父类构造器，设置线程名
    }

    // 2. 重写run()方法（线程执行的任务）
    @Override
    public void run() {
        for (int i = 0; i < 5; i++) {
            // Thread.currentThread()：获取当前执行的线程对象
            System.out.println(Thread.currentThread().getName() + "：执行任务，i=" + i);
            try {
                Thread.sleep(500); // 线程休眠500ms（进入超时等待状态）
            } catch (InterruptedException e) {
                e.printStackTrace();
            }
        }
    }
}

// 测试继承Thread创建线程
public class ThreadCreateDemo1 {
    public static void main(String[] args) {
        // 3. 创建线程对象
        MyThread thread1 = new MyThread("线程A");
        MyThread thread2 = new MyThread("线程B");

        // 4. 启动线程（调用start()，JVM会自动调用run()）
        thread1.start();
        thread2.start();

        // 主线程执行（main方法本身是一个线程）
        for (int i = 0; i < 5; i++) {
            System.out.println("主线程：执行任务，i=" + i);
            try {
                Thread.sleep(500);
            } catch (InterruptedException e) {
                e.printStackTrace();
            }
        }
    }
}
```

- **输出结果（线程并行执行，顺序不固定）**：
    

```
主线程：执行任务，i=0
线程A：执行任务，i=0
线程B：执行任务，i=0
主线程：执行任务，i=1
线程A：执行任务，i=1
线程B：执行任务，i=1
...
```

- **关键注意事项**：
    
    - 启动线程必须调用`start()`，直接调用`run()`会作为普通方法执行（单线程，无并发）。
        
    - 一个线程对象只能调用一次`start()`，多次调用会抛`IllegalThreadStateException`。

### 2. 方式2：实现Runnable接口（笔记16.2.2节，推荐）

- **核心优势**：解决Java单继承限制（自定义类可同时继承其他类，仅实现Runnable接口），更灵活。
    
- **核心步骤**：
    
    1. 自定义类实现`java.lang.Runnable`接口。
        
    2. 重写`run()`方法（任务逻辑）。
        
    3. 创建`Runnable`实现类对象，作为参数传入`Thread`类构造器。
        
    4. 调用`Thread`对象的`start()`方法启动线程。
        
- **实战案例**：
    

```java
// 1. 自定义任务类（实现Runnable）
class MyRunnable implements Runnable {
    @Override
    public void run() {
        for (int i = 0; i < 5; i++) {
            System.out.println(Thread.currentThread().getName() + "：执行任务，i=" + i);
            try {
                Thread.sleep(500);
            } catch (InterruptedException e) {
                e.printStackTrace();
            }
        }
    }
}

// 测试实现Runnable创建线程
public class ThreadCreateDemo2 {
    public static void main(String[] args) {
        // 2. 创建任务对象（Runnable实现类）
        MyRunnable task = new MyRunnable();

        // 3. 创建线程对象，传入任务
        Thread thread1 = new Thread(task, "线程C");
        Thread thread2 = new Thread(task, "线程D");

        // 4. 启动线程
        thread1.start();
        thread2.start();

        // 主线程任务
        for (int i = 0; i < 5; i++) {
            System.out.println("主线程：执行任务，i=" + i);
            try {
                Thread.sleep(500);
            } catch (InterruptedException e) {
                e.printStackTrace();
            }
        }
    }
}
```

- **简化写法（匿名内部类/Lambda）**：
    

```java
// Lambda表达式简化（Runnable是函数式接口，仅一个抽象方法）
public class ThreadLambdaDemo {
    public static void main(String[] args) {
        // 线程E：Lambda简化
        new Thread(() -> {
            for (int i = 0; i < 5; i++) {
                System.out.println("线程E：i=" + i);
                try { Thread.sleep(500); } catch (InterruptedException e) {}
            }
        }, "线程E").start();

        // 线程F：匿名内部类
        new Thread(new Runnable() {
            @Override
            public void run() {
                for (int i = 0; i < 5; i++) {
                    System.out.println("线程F：i=" + i);
                    try { Thread.sleep(500); } catch (InterruptedException e) {}
                }
            }
        }, "线程F").start();
    }
}
```

### 3. 方式3：实现Callable接口（进阶，笔记16.2.3节）

- **核心优势**：相比Runnable，可返回任务执行结果，可抛出异常（Runnable的run()无返回值、不能抛受检异常）。
    
- **核心步骤**：
    
    1. 自定义类实现`java.util.concurrent.Callable<V>`接口（V为返回值类型）。
        
    2. 重写`call()`方法（任务逻辑，返回V类型结果）。
        
    3. 创建`Callable`实现类对象，包装为`FutureTask<V>`对象（用于接收返回结果）。
        
    4. 将`FutureTask`传入`Thread`构造器，调用`start()`启动线程。
        
    5. 调用`FutureTask.get()`获取返回结果（会阻塞主线程，直到任务完成）。
        
- **实战案例**：
    

```java
import java.util.concurrent.Callable;
import java.util.concurrent.ExecutionException;
import java.util.concurrent.FutureTask;

// 1. 自定义任务类（实现Callable，返回Integer类型结果）
class MyCallable implements Callable<Integer> {
    private int start;
    private int end;

    public MyCallable(int start, int end) {
        this.start = start;
        this.end = end;
    }

    // 2. 重写call()方法（有返回值，可抛异常）
    @Override
    public Integer call() throws Exception {
        int sum = 0;
        for (int i = start; i <= end; i++) {
            sum += i;
            System.out.println(Thread.currentThread().getName() + "：计算i=" + i + "，当前和=" + sum);
            Thread.sleep(200);
        }
        return sum; // 返回1~10的和
    }
}

// 测试实现Callable创建线程（带返回值）
public class ThreadCallableDemo {
    public static void main(String[] args) throws ExecutionException, InterruptedException {
        // 2. 创建Callable任务对象
        Callable<Integer> task = new MyCallable(1, 10);

        // 3. 包装为FutureTask（接收返回结果）
        FutureTask<Integer> futureTask = new FutureTask<>(task);

        // 4. 创建线程并启动
        new Thread(futureTask, "计算线程").start();

        // 主线程执行其他任务
        for (int i = 0; i < 5; i++) {
            System.out.println("主线程：处理其他任务，i=" + i);
            Thread.sleep(300);
        }

        // 5. 获取任务返回结果（阻塞，直到任务完成）
        Integer sum = futureTask.get();
        System.out.println("计算线程返回结果：1~10的和=" + sum); // 输出55
    }
}
```

## 三、线程的常用方法（笔记16.3节，高频考点）

Thread类提供大量方法控制线程行为，核心方法如下：

|方法名|作用|注意事项|
|---|---|---|
|`start()`|启动线程，JVM调用`run()`方法|不能重复调用|
|`run()`|线程执行的任务逻辑|直接调用为普通方法，无并发|
|`sleep(long millis)`|线程休眠millis毫秒（进入超时等待状态），释放CPU，不释放锁|需捕获`InterruptedException`|
|`join()`|等待当前线程执行完毕，其他线程阻塞|需捕获`InterruptedException`|
|`yield()`|线程礼让（放弃CPU，回到就绪状态，重新竞争CPU）|礼让不一定成功（取决于CPU调度）|
|`setPriority(int p)`|设置线程优先级（1~10，默认5），优先级高的线程更易获得CPU|仅为调度建议，不保证优先执行|
|`interrupt()`|中断线程（设置中断标志），唤醒休眠/等待的线程（抛`InterruptedException`）|不会直接终止线程，需手动判断中断标志|
|`isInterrupted()`|判断线程是否被中断（中断标志是否为true）|不会清除中断标志|
|`currentThread()`|静态方法，获取当前执行的线程对象|常用於线程内部获取自身对象|

### 实战案例：核心方法应用

```java
public class ThreadMethodDemo {
    public static void main(String[] args) throws InterruptedException {
        // 线程A：测试sleep和interrupt
        Thread threadA = new Thread(() -> {
            for (int i = 0; i < 10; i++) {
                System.out.println("线程A：i=" + i);
                try {
                    Thread.sleep(1000); // 休眠1秒
                } catch (InterruptedException e) {
                    System.out.println("线程A被中断，退出循环");
                    return; // 中断后退出线程
                }
            }
        }, "线程A");

        // 线程B：测试join（主线程等待线程B执行完毕）
        Thread threadB = new Thread(() -> {
            for (int i = 0; i < 5; i++) {
                System.out.println("线程B：i=" + i);
                try { Thread.sleep(500); } catch (InterruptedException e) {}
            }
        }, "线程B");

        // 启动线程A和B
        threadA.start();
        threadB.start();

        // 主线程等待线程B执行完毕（join()）
        System.out.println("主线程等待线程B执行完毕...");
        threadB.join();
        System.out.println("线程B执行完毕，主线程继续执行");

        // 主线程中断线程A（5秒后）
        Thread.sleep(5000);
        threadA.interrupt();
        System.out.println("主线程中断线程A");
    }
}
```

## 四、线程安全问题与同步机制（笔记16.4节，核心难点）

### 1. 线程安全问题的产生（笔记16.4.1节）

当多个线程同时操作**共享资源**（如共享变量、文件、数据库），且操作不是原子性的（不可分割的步骤），会导致数据不一致（如超卖、重复计数）。

#### 实战：线程安全问题演示（售票系统超卖）

```java
// 共享资源：售票系统（10张票）
class TicketSystem implements Runnable {
    private int ticketNum = 10; // 共享变量（多个线程共享）

    @Override
    public void run() {
        while (true) {
            // 非原子操作：判断+售票（多线程并发时会出现超卖）
            if (ticketNum > 0) {
                // 模拟售票延迟（放大线程安全问题）
                try { Thread.sleep(100); } catch (InterruptedException e) {}
                System.out.println(Thread.currentThread().getName() + "卖出第" + ticketNum + "张票");
                ticketNum--;
            } else {
                break;
            }
        }
    }
}

// 测试线程安全问题（3个窗口同时售票）
public class ThreadSafeProblem {
    public static void main(String[] args) {
        TicketSystem ticketSystem = new TicketSystem();
        // 3个线程共享同一个售票系统对象
        new Thread(ticketSystem, "窗口1").start();
        new Thread(ticketSystem, "窗口2").start();
        new Thread(ticketSystem, "窗口3").start();
    }
}
```

#### 输出结果（存在超卖，如卖出第0张票）：

```
窗口1卖出第10张票
窗口2卖出第10张票
窗口3卖出第9张票
窗口1卖出第8张票
窗口2卖出第7张票
窗口3卖出第6张票
窗口1卖出第5张票
窗口2卖出第4张票
窗口3卖出第3张票
窗口1卖出第2张票
窗口2卖出第1张票
窗口3卖出第0张票 // 超卖（线程安全问题）
```

### 2. 同步机制（解决线程安全问题，笔记16.4.2节）

核心思想：**同一时间只允许一个线程操作共享资源**（加锁

），Java提供多种方式：

#### （1）同步代码块（`synchronized`）

```java
class TicketSystemSync implements Runnable {
    private int ticketNum = 10;

    @Override
    public void run() {
        while (true) {
            synchronized (this) { // 锁对象为当前TicketSystemSync实例
                if (ticketNum > 0) {
                    try { Thread.sleep(100); } catch (InterruptedException e) {}
                    System.out.println(Thread.currentThread().getName() + "卖出第" + ticketNum + "张票");
                    ticketNum--;
                } else {
                    break;
                }
            }
        }
    }
}
```

#### （2）同步方法

```java
class TicketSystemSyncMethod implements Runnable {
    private int ticketNum = 10;

    @Override
    public void run() {
        while (true) {
            sellTicket(); // 调用同步方法
        }
    }

    private synchronized void sellTicket() { // 方法加锁
        if (ticketNum > 0) {
            try { Thread.sleep(100); } catch (InterruptedException e) {}
            System.out.println(Thread.currentThread().getName() + "卖出第" + ticketNum + "张票");
            ticketNum--;
        }
    }
}
```

#### （3）Lock锁（`ReentrantLock`）

```java
import java.util.concurrent.locks.Lock;
import java.util.concurrent.locks.ReentrantLock;

class TicketSystemLock implements Runnable {
    private int ticketNum = 10;
    private Lock lock = new ReentrantLock();

    @Override
    public void run() {
        while (true) {
            lock.lock(); // 加锁
            try {
                if (ticketNum > 0) {
                    try { Thread.sleep(100); } catch (InterruptedException e) {}
                    System.out.println(Thread.currentThread().getName() + "卖出第" + ticketNum + "张票");
                    ticketNum--;
                } else {
                    break;
                }
            } finally {
                lock.unlock(); // 解锁
            }
        }
    }
}
```

### 3. 高级线程安全工具（笔记16.4.3节）

- **原子变量类（`AtomicInteger`等）**：使用CAS操作保证线程安全，无需加锁。
    
- **并发容器（`ConcurrentHashMap`、`CopyOnWriteArrayList`）**：在高并发环境下安全访问集合。
    
- **线程局部变量（`ThreadLocal`）**：每个线程有独立副本，避免共享资源竞争。

## 五、线程池与并发框架（笔记16.5节，进阶）

### 1. 线程池概念

- **核心思想**：线程复用，减少创建销毁线程开销，提高性能。
    
- **核心接口/类**：
    
    - `Executor`（顶层接口）
        
    - `ExecutorService`（可提交任务、管理线程池）
        
    - `ThreadPoolExecutor`（线程池核心实现类）
        
    - `ScheduledExecutorService`（可定时/周期任务）
        

### 2. 线程池使用示例

```java
import java.util.concurrent.ExecutorService;
import java.util.concurrent.Executors;

public class ThreadPoolDemo {
    public static void main(String[] args) {
        // 创建固定大小线程池（5个线程）
        ExecutorService pool = Executors.newFixedThreadPool(5);

        // 提交10个任务
        for (int i = 0; i < 10; i++) {
            int taskNum = i;
            pool.execute(() -> {
                System.out.println(Thread.currentThread().getName() + "执行任务" + taskNum);
                try { Thread.sleep(500); } catch (InterruptedException e) {}
            });
        }

        // 关闭线程池
        pool.shutdown();
    }
}
```

### 3. 线程池优势

1. 减少线程创建销毁开销
    
2. 提高资源利用率
    
3. 可统一管理线程（调度策略、异常处理）
