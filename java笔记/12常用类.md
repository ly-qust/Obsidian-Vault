## 一、String类（java.lang.String）—— 笔记 12.1节（重中之重）

### 1. 核心特性（笔记 12.1.1–12.1.2 节）

- **不可变性**：String 对象创建后，其字符序列不能被修改。任何修改操作（拼接、替换）都会创建新对象。
    
- **常量池机制**：字符串字面量会进入常量池，相同内容复用同一个对象。
    
- **final 修饰**：String 类被 final 修饰，不可继承。
    

```java
String s1 = "abc";
String s2 = "abc";
System.out.println(s1 == s2); // true

String s3 = new String("abc");
System.out.println(s1 == s3); // false
System.out.println(s1.equals(s3)); // true
```

### 2. 常用构造方法（笔记 12.1.3 节）

```java
String s1 = "hello";

String s2 = new String("hello");

char[] chars = {'h', 'i'};
String s3 = new String(chars);

byte[] bytes = {97, 98, 99};
String s4 = new String(bytes);
String s5 = new String(bytes, 0, 2);
```

### 3. 核心方法（笔记 12.1.4 节）

#### （1）字符串比较

```java
s1.equals(s2)
s1.equalsIgnoreCase(s2)
s1.compareTo(s2)
```

示例：

```java
String s1 = "abc";
String s2 = "ABC";

System.out.println(s1.equals(s2));          // false
System.out.println(s1.equalsIgnoreCase(s2));// true
System.out.println(s1.compareTo(s2));       // 32
```

#### （2）字符串查找

包含：`contains`、`startsWith`、`endsWith`、`indexOf`、`lastIndexOf`

```java
String s = "hello world";

s.contains("world");
s.startsWith("hello");
s.endsWith("abc");
s.indexOf("l");      // 2
s.lastIndexOf("l");  // 9
```

#### （3）字符串修改（均返回新对象）

- concat
    
- replace
    
- substring
    
- trim
    
- toLowerCase / toUpperCase
    

```java
String s = "  Hello World  ";
String s1 = s.concat("!");
String s2 = s.replace("World", "Java");
String s3 = s.substring(2, 7);
String s4 = s.trim();
String s5 = s.toUpperCase();
```

#### （4）其他常用方法

- length
    
- charAt
    
- toCharArray
    
- split
    

```java
String s = "abc,def,ghi";

s.length();
s.charAt(3);

char[] chars = s.toCharArray();
String[] parts = s.split(",");
```

### 4. String 避坑点

- 频繁修改字符串必须使用 **StringBuilder / StringBuffer**
    
- `==` 比较地址，`equals` 比较内容
    
- 常量池 vs 堆内存的区别
    

```java
String s = "";
for (int i = 0; i < 10000; i++) {
    s += i;  // 千万不要这样做
}
```

### 5. StringBuilder 与 StringBuffer（笔记 12.1.5 节）

- **共同点**：可变字符序列
    
- **区别**：
    
    - StringBuilder：非线程安全，快
        
    - StringBuffer：线程安全，慢，适合多线程
        

```java
StringBuilder sb = new StringBuilder();
sb.append("hello");
sb.append(" world");
sb.insert(5, ",");
sb.replace(6, 11, "Java");
sb.delete(5, 6);

System.out.println(sb.toString());
```

## 二、包装类（Wrapper Class）—— 笔记 12.2 节

### 1. 核心概念

|基本类型|包装类|
|---|---|
|byte|Byte|
|short|Short|
|int|Integer|
|long|Long|
|float|Float|
|double|Double|
|char|Character|
|boolean|Boolean|

### 2. 自动装箱与拆箱（JDK5+）

```java
Integer i1 = 100; // 装箱 valueOf(100)
int i2 = i1;      // 拆箱 intValue()
```

集合必须使用包装类：

```java
List<Integer> list = new ArrayList<>();
list.add(200);
int num = list.get(0);
```

### 3. 缓存机制（重点和坑点）

Integer 缓存：-128 ~ 127

```java
Integer a = 100;
Integer b = 100;
System.out.println(a == b); // true

Integer c = 200;
Integer d = 200;
System.out.println(c == d); // false

c.equals(d); // 正确比较
```

### 4. 包装类常用方法

- parseXxx
    
- valueOf
    
- toBinaryString / toHexString
    

```java
int num = Integer.parseInt("123");
double d = Double.parseDouble("3.14");

String s1 = String.valueOf(456);

System.out.println(Integer.toBinaryString(10));
System.out.println(Integer.toHexString(10));
```

## 三、日期时间类（笔记 12.3 节）

### 1. 传统日期时间类

#### Date

```java
Date date = new Date();
long ts = date.getTime();
```

#### SimpleDateFormat（线程不安全）

```java
SimpleDateFormat sdf = new SimpleDateFormat("yyyy-MM-dd HH:mm:ss");
String str = sdf.format(new Date());
Date date = sdf.parse("2025-11-15 15:30:00");
```

### 2. Java 8 新日期时间 API（重点）

包含：

- LocalDate
    
- LocalTime
    
- LocalDateTime
    
- DateTimeFormatter
    
- Period / Duration
    

#### （1）创建

```java
LocalDateTime now = LocalDateTime.now();
LocalDateTime specified = LocalDateTime.of(2025, 11, 15, 8, 30, 0);
```

#### （2）获取字段

```java
now.getYear();
now.getMonthValue();
now.getDayOfMonth();
now.getHour();
```

#### （3）日期时间修改

```java
now.plusYears(1);
now.minusMonths(1);
now.withDayOfMonth(20);
```

#### （4）格式化与解析

```java
DateTimeFormatter f = DateTimeFormatter.ofPattern("yyyy-MM-dd HH:mm:ss");
String str = now.format(f);
LocalDateTime parsed = LocalDateTime.parse(str, f);
```

#### （5）Period / Duration 差值计算

```java
Period p = Period.between(date1, date2);
Duration d = Duration.between(time1, time2);

d.toHours();
d.toMinutes();
```
