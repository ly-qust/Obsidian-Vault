## 一、网络编程基础（笔记17.1节）

### 1. 核心概念（笔记17.1.1-17.1.2节）

- **网络编程的定义**：通过网络协议（如TCP/IP）实现不同设备（计算机）之间的数据传输与通信（如浏览器访问服务器、客户端发送消息给服务器）。
    
- **核心目标**：实现跨设备数据交互（如文件传输、消息通信、远程调用）。
    
- **关键术语**：
    
    1. **IP地址**：设备在网络中的唯一标识（如`192.168.1.1`、`localhost`对应`127.0.0.1`）。
        
    2. **端口号（Port）**：设备内进程的唯一标识（0-65535，0-1023为系统端口，推荐使用1024以上端口）。
        
    3. **Socket（套接字）**：网络通信的端点，封装了IP地址和端口号，是Java网络编程的核心对象（通过Socket建立连接、传输数据）。
        
    4. **网络协议**：设备间通信的规则（如TCP：可靠传输、面向连接；UDP：不可靠传输、无连接）。
        

### 2. 网络协议分层（OSI/RM模型，笔记17.1.3节）

Java网络编程主要关注**应用层**和**传输层**：

- **传输层核心协议**（开发重点）：
    
    - **TCP（Transmission Control Protocol）**：面向连接、可靠传输（数据不丢失、有序）、面向字节流，适用于文件传输、HTTP通信等（需三次握手建立连接，四次挥手断开连接）。
        
    - **UDP（User Datagram Protocol）**：无连接、不可靠传输（数据可能丢失、无序）、面向数据报，适用于实时通信（如视频通话、游戏）、广播通信等（速度快，无需建立连接）。
        
- **应用层协议**：基于传输层，如HTTP（网页访问）、FTP（文件传输）、SMTP（邮件发送）。
    

### 3. Java网络编程核心API（笔记17.1.4节）

Java提供`java.net`包封装网络编程功能，核心类：

- TCP编程：`ServerSocket`（服务器端，监听端口）、`Socket`（客户端/服务器端通信端点）。
    
- UDP编程：`DatagramSocket`（数据报套接字，发送/接收数据）、`DatagramPacket`（数据报，封装数据、IP、端口）。
    
- URL编程：`URL`（统一资源定位符，如`https://www.baidu.com`）、`URLConnection`（URL连接，读取资源）。

## 二、TCP编程（面向连接，可靠传输）—— 笔记17.2节（核心重点）

TCP编程是开发中最常用的网络通信方式，核心流程为“服务器监听端口→客户端连接→双向通信→断开连接”。

### 1. TCP编程核心流程（笔记17.2.1节）

#### （1）服务器端（Server）流程：

1. 创建`ServerSocket`对象，绑定端口（如8888），监听客户端连接。
    
2. 调用`accept()`方法，阻塞等待客户端连接，连接成功返回`Socket`对象（与客户端通信的端点）。
    
3. 通过`Socket`获取输入流（读取客户端数据）和输出流（向客户端发送数据）。
    
4. 数据交互完成后，关闭流和Socket、ServerSocket。
    

#### （2）客户端（Client）流程：

1. 创建`Socket`对象，指定服务器IP地址和端口（如`127.0.0.1:8888`），发起连接。
    
2. 通过`Socket`获取输出流（向服务器发送数据）和输入流（读取服务器响应）。
    
3. 数据交互完成后，关闭流和Socket。
    

### 2. 实战案例1：TCP客户端与服务器单向通信（服务器接收客户端消息）

#### （1）服务器端代码：

```java
import java.io.*;
import java.net.*;

public class TcpServer {
    public static void main(String[] args) {
        ServerSocket serverSocket = null;
        Socket socket = null;
        InputStream is = null;
        BufferedReader br = null;

        try {
            serverSocket = new ServerSocket(8888);
            System.out.println("TCP服务器启动，监听端口8888...");

            socket = serverSocket.accept();
            System.out.println("客户端连接成功！客户端地址：" + socket.getInetAddress().getHostAddress());

            is = socket.getInputStream();
            br = new BufferedReader(new InputStreamReader(is, "UTF-8"));

            String msg;
            while ((msg = br.readLine()) != null) {
                System.out.println("客户端消息：" + msg);
            }

        } catch (IOException e) {
            e.printStackTrace();
        } finally {
            try {
                if (br != null) br.close();
                if (is != null) is.close();
                if (socket != null) socket.close();
                if (serverSocket != null) serverSocket.close();
            } catch (IOException e) {
                e.printStackTrace();
            }
            System.out.println("服务器关闭！");
        }
    }
}
```

#### （2）客户端代码：

```java
import java.io.*;
import java.net.*;
import java.util.Scanner;

public class TcpClient {
    public static void main(String[] args) {
        Socket socket = null;
        OutputStream os = null;
        BufferedWriter bw = null;
        Scanner scanner = new Scanner(System.in);

        try {
            socket = new Socket("127.0.0.1", 8888);
            System.out.println("连接服务器成功！");

            os = socket.getOutputStream();
            bw = new BufferedWriter(new OutputStreamWriter(os, "UTF-8"));

            String input;
            while (true) {
                System.out.print("请输入要发送的消息（输入exit退出）：");
                input = scanner.nextLine();
                if ("exit".equalsIgnoreCase(input)) {
                    break;
                }
                bw.write(input);
                bw.newLine();
                bw.flush();
            }

        } catch (IOException e) {
            e.printStackTrace();
        } finally {
            try {
                if (bw != null) bw.close();
                if (os != null) os.close();
                if (socket != null) socket.close();
                scanner.close();
            } catch (IOException e) {
                e.printStackTrace();
            }
            System.out.println("客户端关闭！");
        }
    }
}
```

#### （3）运行步骤与结果：

1. 启动服务器：控制台输出“TCP服务器启动，监听端口8888...”。
    
2. 启动客户端：控制台输出“连接服务器成功！”，输入消息（如“Hello Server!”）。
    
3. 服务器接收消息并打印：“客户端消息：Hello Server!”。
    
4. 客户端输入“exit”，关闭客户端，服务器检测到客户端断开，关闭资源。
    

### 3. 实战案例2：TCP双向通信（服务器响应客户端消息）

#### （1）改进后的服务器端（添加响应逻辑）：

```java
OutputStream os = socket.getOutputStream();
BufferedWriter serverBw = new BufferedWriter(new OutputStreamWriter(os, "UTF-8"));
String msg;
while ((msg = br.readLine()) != null) {
    System.out.println("客户端消息：" + msg);
    String response = "服务器已收到消息：" + msg;
    serverBw.write(response);
    serverBw.newLine();
    serverBw.flush();
}
```

#### （2）改进后的客户端（添加接收响应逻辑）：

```java
InputStream is = socket.getInputStream();
BufferedReader clientBr = new BufferedReader(new InputStreamReader(is, "UTF-8"));
String input;
while (true) {
    System.out.print("请输入要发送的消息（输入exit退出）：");
    input = scanner.nextLine();
    if ("exit".equalsIgnoreCase(input)) break;

    bw.write(input);
    bw.newLine();
    bw.flush();

    String response = clientBr.readLine();
    System.out.println("服务器响应：" + response);
}
```

### 4. 实战案例3：TCP文件上传（客户端→服务器）

#### （1）服务器端（接收文件并保存）：

```java
ServerSocket serverSocket = new ServerSocket(9999);
Socket socket = serverSocket.accept();
BufferedInputStream bis = new BufferedInputStream(socket.getInputStream());
BufferedOutputStream bos = new BufferedOutputStream(new FileOutputStream("server_receive.jpg"));

```

## 三、UDP编程（无连接，不可靠传输）

### 1. UDP核心流程

#### （1）发送端流程：

1. 创建`DatagramSocket`对象。
    
2. 封装数据为`DatagramPacket`，指定IP和端口。
    
3. 调用`send()`发送数据报。
    
4. 关闭`DatagramSocket`。
    

#### （2）接收端流程：

1. 创建`DatagramSocket`对象，绑定端口。
    
2. 创建`DatagramPacket`对象接收数据。
    
3. 调用`receive()`阻塞接收数据。
    
4. 提取数据和发送端信息。
    
5. 关闭`DatagramSocket`。
    

### 2. UDP示例

#### 接收端：

```java
DatagramSocket socket = new DatagramSocket(8888);
byte[] buffer = new byte[1024];
DatagramPacket packet = new DatagramPacket(buffer, buffer.length);
socket.receive(packet);
String msg = new String(packet.getData(), 0, packet.getLength(), "UTF-8");
System.out.println("接收来自" + packet.getAddress().getHostAddress() + ":" + packet.getPort() + "的消息：" + msg);
socket.close();
```

#### 发送端：

```java
DatagramSocket socket = new DatagramSocket();
Scanner scanner = new Scanner(System.in);
String msg = scanner.nextLine();
byte[] data = msg.getBytes("UTF-8");
DatagramPacket packet = new DatagramPacket(data, data.length, InetAddress.getByName("127.0.0.1"), 8888);
socket.send(packet);
socket.close(); scanner.close();
```

### 3. UDP与TCP的区别

|对比维度|TCP|UDP|
|---|---|---|
|连接方式|面向连接（三次握手建立连接）|无连接（直接发送，无需建立连接）|
|可靠性|可靠传输（数据不丢失、有序）|不可靠传输（数据可能丢失、无序）|
|数据形式|字节流（无边界）|数据报（有边界）|
|效率|较低|较高|
|适用场景|文件传输、HTTP通信、接口调用|视频通话、游戏、广播、实时监控|
|核心对象|ServerSocket、Socket|DatagramSocket、DatagramPacket|

## 四、URL编程（统一资源定位符）

### 1. URL格式

`协议://IP地址:端口/资源路径?参数#锚点`  
示例：`https://www.baidu.com:80/index.html?wd=java#top`

### 2. URL读取网页示例

```java
URL url = new URL("https://www.baidu.com");
URLConnection conn = url.openConnection();
conn.setConnectTimeout(5000);
BufferedReader br = new BufferedReader(new InputStreamReader(conn.getInputStream(), "UTF-8"));
String line;
while ((line = br.readLine()) != null) {
    System.out.println(line);
}
br.close();
```

## 五、网络编程避坑点

1. **端口占用问题**：`BindException: Address already in use` → 更换端口，避免使用0-1023。
    
2. **中文乱码问题**：字节流转字符流需指定编码（UTF-8），TCP发送端需添加换行符。
    
3. **TCP连接阻塞问题**：`accept()`、`read()`、`connect()`会阻塞，可设置`Socket.setSoTimeout(5000)`。
    
4. **UDP数据丢失问题**：UDP无重传机制，可在应用层实现确认机制；避免发送过大数据。
    
5. **资源关闭顺序**：先关闭流，再关闭Socket/ServerSocket。
    
6. **防火墙/网络问题**：检查服务器IP、端口、防火墙；本地测试用127.0.0.1，跨设备用实际IP。

## 六、第17章核心考点总结

1. **网络编程基础**：IP地址、端口号、Socket、TCP/UDP协议。
    
2. **TCP编程**：服务器监听→accept→IO流交互，客户端Socket→IO流；支持双向通信和文件上传。
    
3. **UDP编程**：发送端DatagramSocket→DatagramPacket→send，接收端DatagramSocket→receive。
    
4. **URL编程**：URL定位资源，URLConnection读取或下载文件。
    
5. **避坑关键**：端口占用、中文乱码、TCP阻塞、UDP丢包、防火墙拦截。
