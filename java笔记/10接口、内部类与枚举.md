# 一、接口（Interface）—— _笔记 10.1（重中之重）_

## 1. 接口核心概念（10.1.1 - 10.1.2）

### ● 本质

接口是一种 **规范/契约**，只规定“能做什么”，不规定“怎么做”。

### ● 语法

```java
public interface 接口名 {
    数据类型 常量名 = 值;          // 常量（public static final）
    返回值 方法名(参数);            // 抽象方法（public abstract）
    
    default 返回值 方法名() {...}   // JDK8 默认方法
    static 返回值 方法名() {...}    // JDK8 静态方法
}
```

### ● 特点总结

- 不能实例化（无构造器）
    
- 类用 `implements` 实现接口
    
- 必须重写接口中的抽象方法
    
- 一个类可以实现多个接口
    
- 接口也可以多继承：`interface A extends B, C`
    

---

## 2. 接口实现与使用（10.1.3 - 10.1.5）

### （1）类实现单个接口

```java
public interface USB {
    int VOLTAGE = 5;
    void read();
    void write();

    default void showInfo() {
        System.out.println("USB设备，电压：" + VOLTAGE + "V");
    }

    static void checkUSB() {
        System.out.println("检查USB设备是否兼容...");
    }
}

class UDisk implements USB {
    @Override
    public void read() { System.out.println("U盘读取数据"); }

    @Override
    public void write() { System.out.println("U盘写入数据"); }

    @Override
    public void showInfo() {
        System.out.println("U盘设备，容量：64GB，电压：" + VOLTAGE + "V");
    }
}
```

测试：

```java
public class InterfaceTest1 {
    public static void main(String[] args) {
        USB usb = new UDisk();
        usb.read();
        usb.write();
        usb.showInfo();
        USB.checkUSB();
    }
}
```

---

### （2）一个类实现多个接口

```java
interface Network { void connect(); }
interface Playable { void play(); }

class SmartPhone implements Network, Playable {
    public void connect() { System.out.println("手机连接WiFi"); }
    public void play() { System.out.println("手机播放音乐"); }
}
```

---

### （3）接口继承接口（多继承）

```java
interface MobileDevice { void powerOn(); }
interface SmartDevice extends MobileDevice { void takePhoto(); }

class IPhone implements SmartDevice {
    public void powerOn() { System.out.println("iPhone开机"); }
    public void takePhoto() { System.out.println("iPhone拍照"); }
}
```

---

## 3. 接口 vs 抽象类（10.1.6）

|对比项|接口|抽象类|
|---|---|---|
|继承|可多实现|单继承|
|方法|抽象 + 默认方法 + 静态方法|抽象 + 普通方法|
|属性|`public static final`|任意属性|
|构造器|无|有|
|设计目的|制定规范|代码复用|

使用场景：

- 定义规范——接口
    
- 有真实继承层级且需复用代码——抽象类

# 二、内部类（Inner Class）—— _笔记 10.2（分类与使用）_

韩顺平笔记内部类分为四类：

1. **成员内部类**
    
2. **局部内部类**
    
3. **匿名内部类（重点）**
    
4. **静态内部类**
    

---

## 1. 成员内部类

定义在外部类成员位置，可访问外部类所有成员。

```java
class Car {
    private String brand = "宝马";

    class Engine {
        private String type = "V8";
        public void start() {
            System.out.println(brand + "汽车的" + type + "发动机启动");
        }
    }

    public Engine getEngine() { return new Engine(); }
}
```

---

## 2. 局部内部类

定义在方法内部。  
访问方法局部变量时，该变量必须为隐式 final。

```java
class Calculator {
    private int base = 10;

    public void calculate(int a) {
        final int b = 5;

        class AddCalculator {
            public int add() { return base + a + b; }
        }

        AddCalculator addCalc = new AddCalculator();
        System.out.println("计算结果：" + addCalc.add());
    }
}
```

---

## 3. 匿名内部类（重点）

开发中最常用，用于临时实现接口或抽象类：

```java
interface Alarm { void ring(); }

class Door {
    public void installAlarm(Alarm alarm) { alarm.ring(); }
}

public class InnerClassTest3 {
    public static void main(String[] args) {
        Door door = new Door();

        // 匿名内部类
        door.installAlarm(new Alarm() {
            public void ring() {
                System.out.println("警报响：呜哇呜哇");
            }
        });
    }
}
```

---

## 4. 静态内部类

不依赖外部类对象，可访问外部类静态成员。

```java
class School {
    private static String name = "北京大学";

    static class SchoolOffice {
        public void showSchoolName() {
            System.out.println("学校名称：" + name);
        }
    }
}
```

# 三、枚举（Enum）—— _笔记 10.3（基础）_

## 1. 核心概念

枚举是一种 **特殊类**，用于定义 **固定、有限** 的常量集合。  
枚举常量本质上是 **枚举类型的对象**。

```java
enum 枚举名 {
    常量1, 常量2, ..., 常量n;
}
```

---

## 2. 基本使用（10.3.2 - 10.3.3）

### ● 简单枚举

```java
enum Weekday {
    MONDAY, TUESDAY, WEDNESDAY, THURSDAY, FRIDAY, SATURDAY, SUNDAY;
}
```

---

### ● 带属性、构造器、方法的枚举

（这是韩顺平笔记重点案例）

```java
enum Gender {
    MALE("男"),
    FEMALE("女");

    private String desc;

    private Gender(String desc) {   // 构造器必须私有
        this.desc = desc;
    }

    public String getDesc() { return desc; }
}
```

使用：

```java
public class EnumTest {
    public static void main(String[] args) {
        Gender g = Gender.MALE;
        System.out.println(g.getDesc());  // 输出：男
    }
}
```
