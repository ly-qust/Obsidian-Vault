## 一、泛型（Generic）—— 笔记14.1节（核心重点）

### 1. 泛型的核心概念（笔记14.1.1节）

- **定义**：泛型是JDK 5引入的特性，允许在定义类、接口、方法时使用“类型参数”（如`<T>`），在使用时指定具体类型（如`List<String>`），实现“类型参数化”。
    
- **核心作用**：
    
    1. **类型安全**：编译时检查类型，避免运行时类型转换异常（如`ClassCastException`）。
        
    2. **代码复用**：同一套代码可适配不同类型（如`List<T>`可存储String、Integer等任意类型）。
        
    3. **简化代码**：无需手动强制类型转换（泛型自动推导类型）。
        
- **泛型的必要性（反例：无泛型的问题）**：
    

```java
// 无泛型：List默认存储Object，存在类型安全问题
List list = new ArrayList();
list.add("Java");
list.add(100); // 编译不报错（允许存储任意类型）

// 取出元素时需强制转换，运行时可能报错
String s = (String) list.get(1); // 运行时抛ClassCastException（100是Integer，不能转String）
```

**有泛型：类型安全，编译时校验**：

```java
List<String> list = new ArrayList<>();
list.add("Java");
// list.add(100); // 编译直接报错（不允许存储非String类型）
String s = list.get(0); // 无需强制转换，编译时确定类型
```

### 2. 泛型的基本语法（笔记14.1.2节）

#### （1）泛型类/接口（含类型参数的类/接口）

- **语法**：
    

```java
// 泛型类：类名后加<T>，T为类型参数（可自定义名称，如E、K、V）
class 类名<T> {
    private T data; // 类型参数作为属性类型
    public T getData() { return data; } // 类型参数作为返回值类型
    public void setData(T data) { this.data = data; } // 类型参数作为参数类型
}

// 泛型接口：接口名后加<T>
interface 接口名<T> {
    T method(T param);
}
```

- **实战案例：泛型类与接口实现**：
    

```java
// 1. 定义泛型类（存储单个数据的容器）
class GenericBox<T> {
    private T content;

    public GenericBox(T content) {
        this.content = content;
    }

    public T getContent() {
        return content;
    }

    public void setContent(T content) {
        this.content = content;
    }

    @Override
    public String toString() {
        return "GenericBox{" + "content=" + content + '}';
    }
}

// 2. 定义泛型接口
interface GenericProcessor<T> {
    T process(T input); // 处理输入数据，返回同类型结果
}

// 3. 实现泛型接口（指定具体类型String）
class StringProcessor implements GenericProcessor<String> {
    @Override
    public String process(String input) {
        return input.toUpperCase(); // 字符串转大写
    }
}

// 4. 测试泛型类与接口
public class GenericClassDemo {
    public static void main(String[] args) {
        // 泛型类使用：指定类型为String
        GenericBox<String> stringBox = new GenericBox<>("Hello");
        String strContent = stringBox.getContent(); // 无需强制转换
        System.out.println(stringBox); // GenericBox{content=Hello}

        // 泛型类使用：指定类型为Integer
        GenericBox<Integer> intBox = new GenericBox<>(100);
        int intContent = intBox.getContent();
        System.out.println(intBox); // GenericBox{content=100}

        // 泛型接口使用
        GenericProcessor<String> processor = new StringProcessor();
        String result = processor.process("java");
        System.out.println(result); // JAVA
    }
}
```

#### （2）泛型方法（含类型参数的方法）

- **语法**：方法返回值前加`<T>`，声明该方法为泛型方法（可独立于泛型类存在）。
    

```java
// 泛型方法：<T>声明类型参数，可用于参数、返回值
public <T> T genericMethod(T param) {
    return param;
}
```

- **实战案例：泛型方法的灵活应用**：
    

```java
public class GenericMethodDemo {
    // 1. 泛型方法：打印任意类型数据
    public static <T> void printData(T data) {
        System.out.println("数据：" + data + "，类型：" + data.getClass().getSimpleName());
    }

    // 2. 泛型方法：交换数组中两个索引的元素（支持任意类型数组）
    public static <T> void swapArray(T[] arr, int i, int j) {
        if (i < 0 || i >= arr.length || j < 0 || j >= arr.length) {
            throw new IndexOutOfBoundsException("索引越界");
        }
        T temp = arr[i];
        arr[i] = arr[j];
        arr[j] = temp;
    }

    // 3. 泛型方法：返回数组中第一个元素
    public static <T> T getFirstElement(T[] arr) {
        if (arr == null || arr.length == 0) {
            return null;
        }
        return arr[0];
    }

    public static void main(String[] args) {
        // 测试打印方法（自动推导类型）
        printData("Java"); // 数据：Java，类型：String
        printData(100); // 数据：100，类型：Integer
        printData(3.14); // 数据：3.14，类型：Double

        // 测试数组交换
        String[] strArr = {"A", "B", "C"};
        swapArray(strArr, 0, 2);
        System.out.println(Arrays.toString(strArr)); // [C, B, A]

        Integer[] intArr = {1, 2, 3};
        swapArray(intArr, 1, 2);
        System.out.println(Arrays.toString(intArr)); // [1, 3, 2]

        // 测试获取第一个元素
        Double[] doubleArr = {1.1, 2.2, 3.3};
        Double first = getFirstElement(doubleArr);
        System.out.println("第一个元素：" + first); // 1.1
    }
}
```

#### （3）泛型通配符（Wildcard）—— 笔记14.1.3节核心

泛型通配符`?`用于表示“任意类型”，解决泛型类型不兼容问题（如`List<String>`不能赋值给`List<Object>`），分为**无界通配符、上限通配符、下限通配符**。

|通配符类型|语法|含义|使用场景|
|---|---|---|---|
|无界通配符|`?`|任意类型|仅读取数据，不修改（如打印任意List）|
|上限通配符|`? extends T`|只能是T或T的子类|限制输入类型（如仅接收Number及其子类）|
|下限通配符|`? super T`|只能是T或T的父类|限制输出类型（如仅接收Integer及其父类）|

- **实战案例：通配符的应用**：
    

```java
public class GenericWildcardDemo {
    // 1. 无界通配符：打印任意类型List（仅读取，不修改）
    public static void printList(List<?> list) {
        for (Object obj : list) {
            System.out.print(obj + " ");
        }
        System.out.println();
    }

    // 2. 上限通配符：计算List中元素的总和（仅接收Number及其子类：Integer、Double等）
    public static double sumList(List<? extends Number> list) {
        double sum = 0;
        for (Number num : list) {
            sum += num.doubleValue(); // Number有doubleValue()方法
        }
        return sum;
    }

    // 3. 下限通配符：向List中添加元素（仅接收Integer及其父类：Number、Object）
    public static void addInteger(List<? super Integer> list) {
        list.add(100); // Integer可向上转型为父类
        list.add(200);
    }

    public static void main(String[] args) {
        // 测试无界通配符
        List<String> strList = Arrays.asList("A", "B", "C");
        List<Integer> intList = Arrays.asList(1, 2, 3);
        printList(strList); // A B C
        printList(intList); // 1 2 3

        // 测试上限通配符
        List<Double> doubleList = Arrays.asList(1.1, 2.2, 3.3);
        double sum = sumList(intList);
        System.out.println("整数列表总和：" + sum); // 6.0
        System.out.println("小数列表总和：" + sumList(doubleList)); // 6.6

        // 测试下限通配符
        List<Number> numberList = new ArrayList<>();
        List<Object> objectList = new ArrayList<>();
        addInteger(numberList);
        addInteger(objectList);
        System.out.println(numberList); // [100, 200]
        System.out.println(objectList); // [100, 200]

        // 错误：List<String>不是Integer的父类，不能传入addInteger
        // List<String> strList2 = new ArrayList<>();
        // addInteger(strList2);
    }
}
```

### 3. 泛型的限制与注意事项（避坑点，笔记14.1.4节）

1. **泛型类型不能是基本数据类型**：需使用包装类（如`List<int>`错误，需`List<Integer>`）。
    
2. **泛型类型参数不能实例化**：如`new T()`错误。
    
3. **泛型类不能直接继承Exception/Throwable**。
    
4. **泛型在静态方法中的限制**：静态方法不能使用泛型类的类型参数，需定义为泛型方法。
    
5. **泛型类型擦除**：编译后泛型信息会被擦除，运行时无法获取。
    

```java
// 错误示例1：泛型类型为基本数据类型
// List<int> intList = new ArrayList<>(); // 编译报错

// 错误示例2：实例化泛型类型参数
class GenericError<T> {
    // public GenericError() { this.data = new T(); } // 编译报错
    private T data;
}

// 错误示例3：静态方法使用泛型类的类型参数
class GenericStatic<T> {
    // public static void method(T param) { } // 编译报错
    // 正确：定义为泛型方法
    public static <E> void method(E param) { }
}
```

## 二、枚举深化（Enum Advanced）—— 笔记14.2节

### 1. 枚举的高级特性（笔记14.2.1节）

- 枚举不仅是“固定常量集合”，还可包含**构造器、属性、方法**，甚至实现接口。
    
- **核心扩展点**：
    
    1. 枚举构造器必须为`private`。
        
    2. 枚举常量可携带自定义属性。
        
    3. 枚举可重写方法或实现接口。
        

---

### 2. 枚举的高级应用实战

#### （1）带属性与构造器的枚举

```java
enum Color {
    RED(255, 0, 0, "红色"),
    GREEN(0, 255, 0, "绿色"),
    BLUE(0, 0, 255, "蓝色"),
    YELLOW(255, 255, 0, "黄色");

    private int r;
    private int g;
    private int b;
    private String desc;

    private Color(int r, int g, int b, String desc) {
        this.r = r;
        this.g = g;
        this.b = b;
        this.desc = desc;
    }

    public int getR() { return r; }
    public int getG() { return g; }
    public int getB() { return b; }
    public String getDesc() { return desc; }

    @Override
    public String toString() {
        return desc + "（RGB：" + r + "," + g + "," + b + "）";
    }

    public static Color getColorByRGB(int r, int g, int b) {
        for (Color color : Color.values()) {
            if (color.r == r && color.g == g && color.b == b) {
                return color;
            }
        }
        return null;
    }
}
```

### 3. 枚举的底层原理（韩顺平笔记补充）

- 枚举本质是`final class`，继承自`java.lang.Enum`。
    
- 枚举常量是`public static final`实例。
    
- 编译器自动生成`values()`和`valueOf(String)`方法。
    

```java
final class Color extends Enum<Color> {
    public static final Color RED = new Color(255, 0, 0, "红色");
    public static final Color GREEN = new Color(0, 255, 0, "绿色");
    private Color(int r, int g, int b, String desc) { ... }
    public static Color[] values() { ... }
    public static Color valueOf(String name) { ... }
}
```

## 三、泛型与枚举的综合实战（笔记14.3节）

```java
enum ValidateRule {
    NOT_EMPTY("^.+$", "字符串不能为空"),
    INT_RANGE("^[1-9]\\d{0,2}$", "整数必须在1-999之间"),
    DATE_FORMAT("^\\d{4}-\\d{2}-\\d{2}$", "日期格式必须为yyyy-MM-dd");

    private String regex;
    private String desc;
    private ValidateRule(String regex, String desc){ this.regex = regex; this.desc = desc; }
    public boolean validate(String data){ return data != null && data.matches(regex); }
    public String getDesc() { return desc; }
}

class DataValidator<T> {
    public interface Converter<T> { String convert(T data); }
    private ValidateRule rule; private Converter<T> converter;
    public DataValidator(ValidateRule rule, Converter<T> converter){ this.rule = rule; this.converter = converter; }
    public boolean validate(T data){
        String strData = converter.convert(data);
        boolean result = rule.validate(strData);
        if(!result) System.out.println("校验失败：" + rule.getDesc());
        return result;
    }
}
```
