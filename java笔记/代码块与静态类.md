### (1)不管调用哪个构造器，创建对象，都应该先调用代码块的内容再调用其他

代码块优先级>构造器
```java
（static）{   //static可选

}
```
### (2) static代码块是类加载时执行，且只会使用一次
(3)普通代码块在创建对象时调用，创建一次，调用一次
4.类加载的三种情况：
创建对象实例时、使用类的静态成员时、创建子类对象实例父类也会被加载
5.创建一个对象时，一个类的调用顺序是：调用静态代码块和静态属性代码块，调用普通代码块和普通属性初始化，调用构造函数
```java
package com.hspedu.codeblock_;  
  
public class CodeBlockDetail02 {  
    public static void main(String[] args) {  
        A a = new A();// (1) A 静态代码块01 (2) getN1被调用...(3)A 普通代码块01(4)getN2被调用...(5)A() 构造器被调用  
    }  
}  
  
class A {  
    public int getN2() { //普通方法/非静态方法  
        System.out.println("getN2被调用...");  
        return 200;  
    }  
    private int n2 = getN2();//普通属性的初始化  
  
    { //普通代码块  
        System.out.println("A 普通代码块01");  
    }  
  
    static { //静态代码块  
        System.out.println("A 静态代码块01");  
    }  
  
    //静态属性的初始化  
    private static  int n1 = getN1();  
  
    public static int getN1() {  
        System.out.println("getN1被调用...");  
        return 100;  
    }  
  
  
    //无参构造器  
    public A() {  
        System.out.println("A() 构造器被调用");  
    }  
  
}

```
