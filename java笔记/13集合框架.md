## 一、集合框架概述（笔记13.1节）

### 1. 集合的核心作用

- **定义**：集合是用于存储批量数据的容器，替代数组的局限性（固定长度、只能存储同类型基本数据类型/对象）。
    
- **优势**：
    
    1. 动态扩容（无需手动指定长度）。
        
    2. 提供丰富的操作方法（添加、删除、查找、排序等）。
        
    3. 支持泛型（类型安全，避免类型转换异常）。
        
    4. 可存储不同类型对象（泛型限制后可统一类型）。
        

### 2. 集合框架体系结构（韩顺平笔记核心图）

Java集合框架以两大根接口为核心，分为“单列集合”和“双列集合”：

```
Java集合框架
├─ 根接口：Collection（单列集合，存储单个元素）
│  ├─ List（有序、可重复、有索引）
│  │  ├─ ArrayList（数组实现，查询快、增删慢）
│  │  ├─ LinkedList（双向链表实现，查询慢、增删快）
│  │  └─ Vector（数组实现，线程安全、效率低，古老类）
│  └─ Set（无序、不可重复、无索引）
│     ├─ HashSet（哈希表实现，无序、去重快）
│     ├─ LinkedHashSet（哈希表+链表实现，有序、去重）
│     └─ TreeSet（红黑树实现，自然排序/定制排序，无重复）
└─ 根接口：Map（双列集合，存储键值对<K,V>）
   ├─ HashMap（哈希表实现，无序、键唯一、值可重复，线程不安全）
   ├─ LinkedHashMap（哈希表+链表实现，有序、键唯一）
   ├─ TreeMap（红黑树实现，键自然排序/定制排序，键唯一）
   └─ Hashtable（哈希表实现，线程安全、效率低，键值不能为null）
```

### 3. 集合与数组的区别（笔记13.1.3节对比）

|对比维度|数组（Array）|集合（Collection/Map）|
|---|---|---|
|长度|固定长度，初始化后不可变|动态扩容，无需指定初始长度|
|存储类型|只能存储同类型基本数据类型/对象|可存储不同类型对象（泛型可限制统一类型）|
|操作方法|无内置方法，需手动实现增删查|提供丰富方法（add/remove/contains等）|
|线程安全|无线程安全特性|部分实现类线程安全（Vector/Hashtable）|
|存储结构|连续内存空间|哈希表/链表/红黑树等多种结构|

## 二、Collection接口（单列集合根接口）—— 笔记13.2节

### 1. 核心特性

- 定义单列集合的通用操作规范，所有单列集合（List/Set）都实现此接口。
    
- 无索引（List子接口新增索引特性），支持添加、删除、遍历、判断等操作。
    

### 2. 常用方法（所有单列集合通用）

```java
import java.util.ArrayList;
import java.util.Collection;
import java.util.Iterator;

public class CollectionDemo {
    public static void main(String[] args) {
        // 1. 创建Collection实现类对象（多态：接口引用指向实现类）
        Collection<String> coll = new ArrayList<>();

        // 2. 添加元素（add()）
        coll.add("Java");
        coll.add("Python");
        coll.add("C++");
        System.out.println("添加后：" + coll); // [Java, Python, C++]

        // 3. 批量添加元素（addAll()）
        Collection<String> coll2 = new ArrayList<>();
        coll2.add("Go");
        coll2.add("PHP");
        coll.addAll(coll2);
        System.out.println("批量添加后：" + coll); // [Java, Python, C++, Go, PHP]

        // 4. 判断元素是否存在（contains()）
        System.out.println("是否包含Java：" + coll.contains("Java")); // true

        // 5. 判断批量元素是否都存在（containsAll()）
        System.out.println("是否包含coll2所有元素：" + coll.containsAll(coll2)); // true

        // 6. 删除元素（remove()，删除第一个匹配的元素）
        coll.remove("PHP");
        System.out.println("删除PHP后：" + coll); // [Java, Python, C++, Go]

        // 7. 批量删除元素（removeAll()，删除交集元素）
        coll.removeAll(coll2); // coll2中剩余"Go"，删除后coll中"Go"被移除
        System.out.println("批量删除后：" + coll); // [Java, Python, C++]

        // 8. 元素个数（size()）
        System.out.println("集合大小：" + coll.size()); // 3

        // 9. 清空集合（clear()）
        coll2.clear();
        System.out.println("coll2清空后：" + coll2); // []

        // 10. 判断集合是否为空（isEmpty()）
        System.out.println("coll2是否为空：" + coll2.isEmpty()); // true

        // 11. 转换为数组（toArray()）
        Object[] arr = coll.toArray();
        for (Object o : arr) {
            System.out.print(o + " "); // Java Python C++
        }
    }
}
```

### 3. Collection遍历方式（笔记13.2.2节核心）

所有Collection集合支持3种遍历方式：迭代器、增强for、Lambda表达式（JDK8+）。

#### （1）迭代器（Iterator）—— 最基础、最安全的遍历方式

```java
Collection<String> coll = new ArrayList<>();
coll.add("Java");
coll.add("Python");
coll.add("C++");

// 1. 获取迭代器对象
Iterator<String> it = coll.iterator();

// 2. 遍历：hasNext()判断是否有下一个元素，next()获取元素
while (it.hasNext()) {
    String elem = it.next();
    System.out.println(elem);
    // 迭代器遍历中删除元素（必须用it.remove()，不能用coll.remove()，否则抛ConcurrentModificationException）
    if ("Python".equals(elem)) {
        it.remove();
    }
}
System.out.println("删除Python后：" + coll); // [Java, C++]
```

#### （2）增强for循环（foreach）—— 简洁遍历，不可修改集合结构

```java
for (String elem : coll) {
    System.out.println(elem);
    // 此处不能用coll.remove(elem)，会抛ConcurrentModificationException
}
```

#### （3）Lambda表达式（JDK8+）—— 极简遍历

```java
coll.forEach(elem -> System.out.println(elem));
// 简化写法（方法引用）
coll.forEach(System.out::println);
```

## 三、List接口（有序、可重复、有索引）—— 笔记13.3节

### 1. 核心特性（笔记13.3.1节）

- 继承自Collection接口，新增“索引操作”方法（基于索引添加、删除、查找）。
    
- 核心特点：有序（元素存入顺序=取出顺序）、可重复（允许元素值相同）、有索引（支持随机访问）。
    

### 2. List接口常用方法（新增索引相关方法）

```java
List<String> list = new ArrayList<>();
list.add("Java");
list.add("Python");
list.add("C++");

// 1. 按索引添加元素（插入到指定位置）
list.add(1, "Go"); // list = [Java, Go, Python, C++]

// 2. 按索引获取元素
System.out.println("索引1的元素：" + list.get(1)); // Go

// 3. 按索引修改元素（返回被替换的旧元素）
String oldElem = list.set(2, "PHP"); // list = [Java, Go, PHP, C++]
System.out.println("被替换的旧元素：" + oldElem); // Python

// 4. 按索引删除元素（返回被删除的元素）
String removedElem = list.remove(3); // list = [Java, Go, PHP]
System.out.println("被删除的元素：" + removedElem); // C++

// 5. 查找元素首次出现的索引（未找到返回-1）
int index = list.indexOf("Go");
System.out.println("Go的索引：" + index); // 1

// 6. 查找元素最后出现的索引
list.add("Go"); // list = [Java, Go, PHP, Go]
int lastIndex = list.lastIndexOf("Go");
System.out.println("Go最后出现的索引：" + lastIndex); // 3

// 7. 截取子列表（左闭右开，返回新List，修改会影响原列表）
List<String> subList = list.subList(1, 3); // [Go, PHP]
subList.set(0, "JavaScript");
System.out.println("原列表修改后：" + list); // [Java, JavaScript, PHP, Go]
```

### 3. List三大实现类对比（笔记13.3.2-13.3.4节核心）

|实现类|底层结构|线程安全|查询效率|增删效率（中间位置）|特点与使用场景|
|---|---|---|---|---|---|
|ArrayList|动态数组|否|高（随机访问）|低（需移动元素）|单线程、查询频繁场景（推荐）|
|LinkedList|双向链表|否|低（需遍历）|高（仅修改指针）|单线程、增删频繁场景|
|Vector|动态数组|是（方法加synchronized）|高|低|多线程场景（古老类，推荐用Collections.synchronizedList替代）|

### 4. 三大实现类实战案例

#### （1）ArrayList（最常用）

```java
// 构造方法
List<String> arrayList1 = new ArrayList<>(); // 空列表，初始容量10，扩容因子0.5
List<String> arrayList2 = new ArrayList<>(20); // 指定初始容量（避免频繁扩容）
List<String> arrayList3 = new ArrayList<>(coll); // 基于其他集合创建

// 常用操作
arrayList1.add("A");
arrayList1.add("B");
arrayList1.add("A"); // 允许重复
System.out.println(arrayList1); // [A, B, A]
```

#### （2）LinkedList（增删快）

```java
LinkedList<String> linkedList = new LinkedList<>();
linkedList.add("A");
linkedList.add("B");

// 新增特有方法（链表首尾操作，效率极高）
linkedList.addFirst("头"); // 头部添加
linkedList.addLast("尾"); // 尾部添加
System.out.println(linkedList); // [头, A, B, 尾]

System.out.println(linkedList.getFirst()); // 获取头部元素
System.out.println(linkedList.getLast()); // 获取尾部元素

linkedList.removeFirst(); // 删除头部元素
linkedList.removeLast(); // 删除尾部元素
System.out.println(linkedList); // [A, B]
```

#### （3）Vector（线程安全）

```java
Vector<String> vector = new Vector<>();
vector.add("A");
vector.add("B");
System.out.println(vector); // [A, B]
// 特有方法：elementAt()（等价于get()）
System.out.println(vector.elementAt(0)); // A
```

## 四、Set接口（无序、不可重复、无索引）—— 笔记13.4节

### 1. 核心特性（笔记13.4.1节）

- 继承自Collection接口，无新增方法（完全复用Collection方法）。
    
- 核心特点：无序（存入顺序≠取出顺序，HashSet为例）、不可重复（元素值唯一）、无索引（不支持随机访问，不能用普通for循环遍历）。
    
- 去重机制：依赖元素的`equals()`和`hashCode()`方法（HashSet/LinkedHashSet）。
    

### 2. Set三大实现类对比（笔记13.4.2-13.4.4节核心）

|实现类|底层结构|有序性|去重机制|特点与使用场景|
|---|---|---|---|---|
|HashSet|哈希表（数组+链表/红黑树）|否|依赖元素的hashCode()和equals()|单线程、去重优先、无需顺序|
|LinkedHashSet|哈希表+双向链表|是（插入顺序）|同HashSet，链表维护顺序|单线程、去重+保留插入顺序|
|TreeSet|红黑树（排序树）|是（排序顺序）|自然排序（元素实现Comparable）或定制排序（Comparator）|单线程、去重+排序需求|

### 3. 三大实现类实战案例

#### （1）HashSet（去重核心）

- **去重规则**：
    
    1. 先调用元素的`hashCode()`方法，计算哈希值（决定元素存入哈希表的位置）。
        
    2. 若哈希值不同，直接存入；若哈希值相同，再调用`equals()`方法：
        
        - `equals()`返回true：视为同一元素，拒绝存入；
            
        - `equals()`返回false：视为不同元素，存入同一哈希值位置（链表/红黑树）。
            
- **实战**：自定义对象去重（必须重写`hashCode()`和`equals()`）
    

```java
// 自定义对象：Person（需重写hashCode()和equals()实现去重）
class Person {
    private String name;
    private int age;

    public Person(String name, int age) {
        this.name = name;
        this.age = age;
    }

    // 重写equals()：姓名和年龄相同视为同一人
    @Override
    public boolean equals(Object o) {
        if (this == o) return true;
        if (o == null || getClass() != o.getClass()) return false;
        Person person = (Person) o;
        return age == person.age && Objects.equals(name, person.name);
    }

    // 重写hashCode()：姓名和年龄相同，哈希值相同
    @Override
    public int hashCode() {
        return Objects.hash(name, age);
    }

    @Override
    public String toString() {
        return "Person{" + "name='" + name + '\'' + ", age=" + age + '}';
    }
}

// HashSet去重测试
public class HashSetDemo {
    public static void main(String[] args) {
        Set<Person> personSet = new HashSet<>();
        personSet.add(new Person("张三", 20));
        personSet.add(new Person("张三", 20)); // 重复，无法存入
        personSet.add(new Person("李四", 22));

        System.out.println(personSet); // [Person{name='张三', age=20}, Person{name='李四', age=22}]
    }
}
```

#### （2）LinkedHashSet（去重+保留顺序）

```java
Set<String> linkedHashSet = new LinkedHashSet<>();
linkedHashSet.add("C");
linkedHashSet.add("A");
linkedHashSet.add("B");
linkedHashSet.add("A"); // 重复，无法存入
System.out.println(linkedHashSet); // [C, A, B]（保留插入顺序）
```

#### （3）TreeSet（去重+排序）

- **排序方式**：
    
    1. 自然排序：元素实现`Comparable`接口，重写`compareTo()`方法。
        
    2. 定制排序：创建TreeSet时传入`Comparator`接口实现类（匿名内部类/Lambda）。
        
- **实战**：
    

```java
// 1. 自然排序（String已实现Comparable，按字典序排序）
Set<String> treeSet1 = new TreeSet<>();
treeSet1.add("C");
treeSet1.add("A");
treeSet1.add("B");
System.out.println(treeSet1); // [A, B, C]（自然排序）

// 2. 定制排序（整数降序）
Set<Integer> treeSet2 = new TreeSet<>((o1, o2) -> o2 - o1); // Lambda表达式：o2-o1降序
treeSet2.add(3);
treeSet2.add(1);
treeSet2.add(2);
System.out.println(treeSet2); // [3, 2, 1]（定制降序）

// 3. 自定义对象排序（按年龄升序）
Set<Person> treeSet3 = new TreeSet<>((p1, p2) -> p1.getAge() - p2.getAge());
treeSet3.add(new Person("张三", 20));
treeSet3.add(new Person("李四", 18));
treeSet3.add(new Person("王五", 22));
System.out.println(treeSet3); // [Person{name='李四', age=18}, Person{name='张三', age=20}, Person{name='王五', age=22}]
```

## 五、Map接口（双列集合，键值对<K,V>）—— 笔记13.5节

### 1. 核心特性（笔记13.5.1节）

- **定义**：存储键值对（Key-Value）映射关系，键（Key）唯一，值（Value）可重复。
    
- 核心特点：
    
    1. 键唯一（重复键会覆盖旧值）。
        
    2. 键值对之间一一对应（一个键对应一个值）。
        
    3. 支持泛型（`Map<K,V>`，K为键类型，V为值类型）。
        

### 2. Map接口常用方法

```java
Map<String, Integer> map = new HashMap<>();

// 1. 添加键值对（put()：键不存在添加，存在则覆盖旧值，返回旧值）
map.put("Java", 100);
map.put("Python", 80);
map.put("C++", 90);
map.put("Java", 120); // 覆盖旧值，返回100
System.out.println(map); // {Java=120, Python=80, C++=90}

// 2. 按键获取值（get()：键不存在返回null）
System.out.println("Java对应的值：" + map.get("Java")); // 120
System.out.println("Go对应的值：" + map.get("Go")); // null

// 3. 按键删除键值对（remove()：返回被删除的值）
Integer removedValue = map.remove("Python");
System.out.println("被删除的值：" + removedValue); // 80
System.out.println("删除后：" + map); // {Java=120, C++=90}

// 4. 判断键/值是否存在
System.out.println("是否包含键Java：" + map.containsKey("Java")); // true
System.out.println("是否包含值90：" + map.containsValue(90)); // true

// 5. 获取所有键（keySet()）
Set<String> keys = map.keySet();
for (String key : keys) {
    System.out.print(key + " "); // Java C++
}

// 6. 获取所有值（values()）
Collection<Integer> values = map.values();
for (Integer value : values) {
    System.out.print(value + " "); // 120 90
}

// 7. 获取所有键值对（entrySet()，常用遍历方式）
Set<Map.Entry<String, Integer>> entries = map.entrySet();
for (Map.Entry<String, Integer> entry : entries) {
    String key = entry.getKey();
    Integer value = entry.getValue();
    System.out.println(key + "=" + value); // Java=120, C++=90
}

// 8. 集合大小
System.out.println("键值对个数：" + map.size()); // 2

// 9. 清空集合
map.clear();
System.out.println("清空后：" + map); // {}
```

### 3. Map四大实现类对比（笔记13.5.2-13.5.5节核心）

|实现类|底层结构|线程安全|有序性|键/值是否可为null|特点与使用场景|
|---|---|---|---|---|---|
|HashMap|哈希表（数组+链表/红黑树）|否|否|键最多1个null，值可多个null|单线程、键值对存储（推荐）|
|LinkedHashMap|哈希表+双向链表|否|是（插入顺序）|同HashMap|单线程、键值对+保留插入顺序|
|TreeMap|红黑树|否|是（排序顺序）|键不能为null，值可null|单线程、键值对+排序需求|
|Hashtable|哈希表|是（方法加synchronized）|否|键/值都不能为null|多线程场景（古老类，推荐用ConcurrentHashMap替代）|

### 4. 实现类实战案例

#### （1）HashMap（最常用）

```java
Map<String, String> hashMap = new HashMap<>();
hashMap.put("name", "张三");
hashMap.put("age", "20");
hashMap.put(null, "空键"); // 键允许1个null
hashMap.put("gender", null); // 值允许null
hashMap.put("gender", "男"); // 覆盖值为"男"
System.out.println(hashMap); // {null=空键, name=张三, age=20, gender=男}
```

#### （2）LinkedHashMap（有序）

```java
Map<String, Integer> linkedHashMap = new LinkedHashMap<>();
linkedHashMap.put("C", 3);
linkedHashMap.put("A", 1);
linkedHashMap.put("B", 2);
System.out.println(linkedHashMap); // {C=3, A=1, B=2}（保留插入顺序）
```

#### （3）TreeMap（排序）

```java
// 自然排序（键按字典序）
Map<String, Integer> treeMap1 = new TreeMap<>();
treeMap1.put("C", 3);
treeMap1.put("A", 1);
treeMap1.put("B", 2);
System.out.println(treeMap1); // {A=1, B=2, C=3}（自然排序）

// 定制排序（键降序）
Map<String, Integer> treeMap2 = new TreeMap<>((k1, k2) -> k2.compareTo(k1));
treeMap2.put("C", 3);
treeMap2.put("A", 1);
treeMap2.put("B", 2);
System.out.println(treeMap2); // {C=3, B=2, A=1}（定制降序）
```

#### （4）Hashtable（线程安全）

```java
Map<String, String> hashtable = new Hashtable<>();
hashtable.put("name", "李四");
hashtable.put("age", "22");
// hashtable.put(null, "空键"); // 报错（键不能为null）
// hashtable.put("gender", null); // 报错（值不能为null）
System.out.println(hashtable); // {name=李四, age=22}
```

## 六、集合工具类Collections（笔记13.6节）

### 1. 核心作用

提供静态方法操作集合（排序、查找、同步化、批量添加等），操作对象为Collection/List/Map。

### 2. 常用方法实战

```java
// 1. 排序（仅List）
List<Integer> list = new ArrayList<>();
list.add(3);
list.add(1);
list.add(2);
Collections.sort(list); // 自然升序
System.out.println("排序后：" + list); // [1, 2, 3]

// 2. 定制排序（List）
Collections.sort(list, (o1, o2) -> o2 - o1); // 降序
System.out.println("定制排序后：" + list); // [3, 2, 1]

// 3. 查找（List）
int index = Collections.binarySearch(list, 2); // 二分查找（需先排序）
System.out.println("2的索引：" + index); // 1

// 4. 替换所有元素（List）
Collections.fill(list, 0);
System.out.println("填充后：" + list); // [0, 0, 0]

// 5. 拷贝集合（List）
List<Integer> dest = new ArrayList<>(Collections.nCopies(3, 0)); // 目标集合（长度需>=源集合）
Collections.copy(dest, list);
System.out.println("拷贝后：" + dest); // [0, 0, 0]

// 6. 线程安全化（将非线程安全集合转为线程安全）
List<String> syncList = Collections.synchronizedList(new ArrayList<>());
Set<String> syncSet = Collections.synchronizedSet(new HashSet<>());
Map<String, String> syncMap = Collections.synchronizedMap(new HashMap<>());

// 7. 获取集合最大值/最小值
List<Integer> numList = Arrays.asList(1, 3, 2);
System.out.println("最大值：" + Collections.max(numList)); // 3
System.out.println("最小值：" + Collections.min(numList)); // 1
```

## 七、第13章核心考点总结（韩顺平笔记重点提炼）

1. **集合体系结构**：
    
    - 区分单列集合（Collection）和双列集合（Map），掌握List/Set/Map的核心特性（有序/无序、可重复/不可重复、有索引/无索引）。
        
2. **核心实现类对比（高频考点）**：
    
    - List：ArrayList（查询快）vs LinkedList（增删快）vs Vector（线程安全）。
        
    - Set：HashSet（去重）vs LinkedHashSet（去重+顺序）vs TreeSet（去重+排序）。
        
    - Map：HashMap（常用）vs LinkedHashMap（顺序）vs TreeMap（排序）vs Hashtable（线程安全）。
        
3. **去重与排序机制**：
    
    - HashSet去重：依赖元素的`hashCode()`和`equals()`（必须重写）。
        
    - TreeSet/TreeMap排序：自然排序（`Comparable`）vs 定制排序（`Comparator`）。
        
4. **遍历方式**：
    
    - Collection/Set：迭代器、增强for、Lambda。
        
    - List：额外支持普通for（索引）。
        
    - Map：keySet（遍历键）、values（遍历值）、entrySet（遍历键值对，推荐）。
        
5. **避坑点**：
    
    - 迭代器遍历中修改集合：必须用`Iterator.remove()`，不能用集合自身`remove()`。
        
    - HashMap键为自定义对象：必须重写`hashCode()`和`equals()`，否则无法去重。
        
    - TreeSet存储自定义对象：必须实现`Comparable`或传入`Comparator`，否则抛`ClassCastException`。
        

本章内容是Java开发的“数据容器核心”，几乎所有项目都会用到（如存储查询结果、批量处理数据），需结合大量实战练习熟练掌握不同集合的适用场景（如查询多用ArrayList，去重多用HashSet，键值对多用HashMap）。下一章将学习“泛型与枚举深化”，与集合框架结合紧密，需打好本章基础。
