该文档详细梳理了Java日期时间相关的核心知识，核心结论是Java 8+推荐使用`java.time`包下的新API，老旧的Date和Calendar类因设计缺陷不建议优先使用。 ### 一、核心API分类与对比 - **传统日期类**：包括Date、Calendar、GregorianCalendar，线程不安全且可变，Java 1.0+引入，存在较多设计缺陷。 - **新日期时间类**：Java 8+新增，线程安全且不可变，包含LocalDate（日期）、LocalTime（时间）、LocalDateTime（日期时间）、ZonedDateTime（带时区）等，功能完善。 - **辅助类**：Instant（时间戳，精确到纳秒）、DateTimeFormatter（线程安全的格式化工具）、SimpleDateFormat（传统格式化类，线程不安全）。 ### 二、关键使用要点 1. **API选择**：新项目优先用`java.time`包，需时区用ZonedDateTime，无需时区用LocalDate/LocalTime/LocalDateTime。 2. **格式化**：避免使用SimpleDateFormat，优先选择DateTimeFormatter保证线程安全。 3. **日期操作**：新API支持直接通过`plusXxx()`、`minusXxx()`进行日期加减，传统类需通过Calendar的add()方法实现。 4. **日期比较**：Date类可通过getTime()、before()/after()/equals()、compareTo()三种方式比较，新API支持更直观的比较方法。 5. **数据库交互**：JDBC 4.2+直接支持`java.time`类型，旧版本需转换为java.sql.Date/Timestamp。 ### 三、常用功能示例 - **获取当前时间**：LocalDate.now()、LocalDateTime.now()、Instant.now()（新API）；new Date()（传统类）。 - **格式化与解析**：DateTimeFormatter指定格式模式，通过format()格式化、parse()解析字符串；printf可通过%t系列转换符快速格式化。 - **时间控制**：Thread.sleep()可实现线程休眠，System.currentTimeMillis()可用于测量时间间隔。 要不要我帮你整理一份**Java日期时间API核心用法速查表**，方便快速查阅关键方法和示例代码？
