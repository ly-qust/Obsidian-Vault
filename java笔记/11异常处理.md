# 一、异常的基本概念（11.1–11.2）

## ✔ 1. 什么是异常？

- 程序运行过程中出现的 “不正常情况”，如
    
    - 除 0
        
    - 数组越界
        
    - 文件不存在
        
- 异常本质：
    
    > **Java 中的类**。  
    > JVM 在异常发生时会创建异常对象并抛出。
    

### 示例

```java
public class ExceptionDemo1 {
    public static void main(String[] args) {
        int a = 10;
        int b = 0;
        System.out.println(a / b); // ArithmeticException
        System.out.println("程序继续执行"); 
    }
}
```

运行结果：

```
Exception in thread "main" java.lang.ArithmeticException: / by zero
```

---

## ✔ 2. 异常体系结构（重点）

Java 所有异常继承自 `Throwable`：

```
Throwable
├─ Error（严重错误：OOM、栈溢出，不能处理）
└─ Exception（可处理）
     ├─ RuntimeException（运行时异常：空指针/越界/算术）
     └─ 非 RuntimeException（编译时：IOException、SQLException）
```

---

## ✔ 3. 为什么要处理异常？

- 防止程序崩溃，提高健壮性。
    
- 保存日志，方便定位问题。
    
- 控制异常传播，保证核心流程安全。
    

---

# 二、异常处理机制（11.3–11.5）

Java 提供三种手段：

1. **try-catch-finally** — 捕获并处理
    
2. **throws** — 声明异常（交给调用者）
    
3. **throw** — 手动抛出异常对象
    

---

# 1. try-catch-finally

## ✔ （1）语法

```java
try {
    // 可能产生异常的代码
} catch (异常类型1 e) {
    // 针对异常1的处理逻辑
} catch (异常类型2 e) {
    // 针对异常2的处理逻辑
} finally {
    // 无论是否异常都执行（资源释放）
}
```

---

## ✔（2）执行流程（韩顺平笔记重点）

- try 有异常 → 转入匹配的 catch → 执行 finally
    
- try 无异常 → 跳过 catch → 执行 finally
    
- try/catch 有 return → finally 仍然会执行（return 前）
    

---

## ✔（3）完整示例：输入错误处理

```java
try {
    int a = Integer.parseInt(scanner.next());
    int b = Integer.parseInt(scanner.next());
    System.out.println(a / b);
} catch (NumberFormatException e) {
    System.out.println("请输入有效整数！");
} catch (ArithmeticException e) {
    System.out.println("除数不能为 0！");
} finally {
    scanner.close();
}
```

（测试用例呈现略，大纲已整理）

---

## ✔（4）多 catch 注意点

### ⚠ 子类在前，父类在后！（关键考点）

```java
// 错误写法
catch (Exception e) { }
catch (NumberFormatException e) { } // 永远执行不到
```

### JDK7+ 合并写法

```java
catch (NumberFormatException | ArithmeticException e) {
    ...
}
```

# 2. throws —— 声明异常，由调用者处理

## ✔ （1）语法

```java
public void method() throws IOException, SQLException {
    ...
}
```

## ✔ （2）示例：文件读取

```java
public static void readFile(String path) throws FileNotFoundException {
    new FileInputStream(path);
}
```

调用时必须处理：

```java
try {
    FileUtil.readFile("D:/test.txt");
} catch (FileNotFoundException e) { ... }
```

## ✔（3）规则总结

- 编译时异常：必须处理（try 或 throws）
    
- 运行时异常：可处理可不处理（JVM 会自动向外抛）
    
- main 最终把异常交给 JVM（程序终止）
    

---

# 3. throw —— 手动抛出异常对象

## ✔（1）语法

```java
throw new IllegalArgumentException("信息");
```

## ✔（2）用法例子：参数校验

```java
if (age < 0 || age > 150) {
    throw new IllegalArgumentException("年龄无效：" + age);
}
```

## ✔（3）throw vs throws（必考区别）

|关键点|throw|throws|
|---|---|---|
|位置|方法体内部|方法声明处|
|作用|真的“扔出去”一个异常对象|告诉调用者“我可能会抛异常”|
|执行？|会立刻中断|不中断，只是声明|

# 三、自定义异常（11.6）

## ✔（1）步骤

1. 继承 Exception（编译时）或 RuntimeException（运行时）
    
2. 实现构造器（无参 + 带 message）
    
3. 在业务中手动 throw 抛出
    

---

## ✔（2）案例：余额不足异常

```java
class InsufficientFundsException extends Exception {
    public InsufficientFundsException() {}
    public InsufficientFundsException(String msg) { super(msg); }
}
```

业务中抛出：

```java
if (amount > balance) {
    throw new InsufficientFundsException("余额不足");
}
```

# 四、异常处理最佳实践（韩顺平笔记总结）

## ✔（1）不要过度捕获（不要 try 包全局）

## ✔（2）不要用 “catch(Exception e)” 捕获全部，除非最后兜底

## ✔（3）finally 用于资源关闭（文件、数据库连接）

## ✔（4）运行时异常尽量通过规范代码避免，而不是依赖捕获

```java
try {
    fis = new FileInputStream("test.txt");
} finally {
    if (fis != null) fis.close();
}
```

---

# 五、本章核心总结（考试与面试重点）

- **异常体系：Throwable → Error / Exception → RuntimeException**
    
- **try-catch-finally：finally 必执行，子类在前父类在后**
    
- **throws 声明，throw 手动抛出**
    
- **自定义异常：继承 + 构造器**
    
- **资源释放一定放 finally**
