## 参考答案要点

1. 连接超时防止连不上无限等待，读取超时防止上游不返回；还要控制重试总预算。
2. 401/参数错误通常不可重试；429/部分 5xx/短暂网络错误可有限退避重试；解析失败先保留原文并走降级。
3. 密钥可被提交、日志收集或提示词注入泄露；使用环境变量/密钥管理，日志脱敏。
4. Context 是本次输入；Memory 跨请求保存会话；RAG 提供外部事实证据，三者都不能替代权限与业务规则。
5. userId 绑定 conversationId，限制历史范围，并处理 TTL、删除和并发写入。
6. JSON 形状正确不代表字段类型、枚举、范围和业务状态正确；不通过不能直接落库。
7. 文档 → 清洗/切片 → Embedding → 索引；问题 → 改写 → 过滤/召回 → 重排 → Top-K → Prompt → 模型/兜底。
8. 太大导致相关性差和上下文浪费；太小丢失语义，需要按标题和语义边界平衡。
9. 用 scope/source metadata、意图路由和回答口径提示，信息不足时澄清。
10. 无命中先澄清；低分返回安全提示或固定模板；模型失败用可靠片段兜底，否则明确不可用。
11. 已实现 Controller 鉴权、会话/路由、知识加载与检索、引用、模型可选调用和降级；不能把截图中的 LangChain4j AI Service、Tool Calling、MCP、完整生产向量库或流式服务说成项目已实现。
12. 审核、额度、发券和核销需要权限、事务、状态机、唯一约束和并发控制；模型只做解释，避免幻觉改变资金和业务事实。
