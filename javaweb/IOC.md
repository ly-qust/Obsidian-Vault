启动 → 扫描 → 解析注解 → 反射创建对象 → 放入容器

|                 |         |                |
| --------------- | ------- | -------------- |
|                 |         |                |
| 注解              | 含义      | 适用场景           |
| @Component      | 通用组件    | 基础类            |
| @Service        | 业务逻辑层   | Service        |
| @Repository     | 持久层     | DAO            |
| @Controller     | 控制层     | MVC Controller |
| @RestController | REST 接口 | 返回 JSON        |
